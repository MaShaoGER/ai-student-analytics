## 数据标签校正

预览固定标签 2024J → 2025J 与当前 CSV 不一致。当前 72.72 → 69.65、199/200 的真实学期是 **2025B → 2025J**；2024J 为 69.99（200 样本）。正式代码使用实际查询范围，未改写数据满足演示。说明已同步到规格与预览文档。

## 部署与运行

使用 [正式体验说明](ai-conversation-experience.md) 和 [历史存储说明](ai-conversation-storage.md)。保持 `APP_STATE_DIR` 持久化。服务停机期间不做物理删除；重启先清理，所有访问仍以服务端到期边界拒绝。新备份排除 `system/conversations`；自定义备份需同样排除或遵守相同保留期。

当前仍采用本机文件锁和账号有界 JSON 桶，不宣称已经完成多主机数据库能力。保存失败的进程内结果仅有五分钟恢复窗口，服务重启不可恢复未保存结果；界面区分保存失败与分析失败。
