# 正式版地址与图表收尾

用户确认：网站图标与统计图表都重做，完成验证后提交、推送并更新现有 VPS。

## 目标与边界
- 对外地址不出现 demo，使用 /explore、/explore/course、/explore/metric、/chat、/reports、/settings、/admin；默认主题和画法不重复进入查询参数。
- 合成数据对外标识 source=sample；API、权限、数据库和已有会话保留内部稳定 ID，不冒充真实教学数据。已有收藏地址可读，进入后只生成新的规范地址。
- 保持课程→指标→关系、前进后退、刷新、阅读位置、角色权限与少于 3 人抑制规则。
- 图标使用现有刻度尺标识；图表统一暖白 #f5f5f2、近黑 #232329、淡紫 #7666cc 及其明暗层级。保留可见标签、数值表、线型与缺失纹理，不依赖颜色区分数据。禁止普通图表容器模糊。
- 更新 README、工作台指南、架构和部署记录。部署备份现有配置和 records，只替换 app，不重置账号、密钥或持久化卷，不改其他服务。
- 自签名证书问题不属于换 URL 可解决的事项；未经授权不更改域名、DNS 或证书信任设置。

## 方案取舍
保留长查询地址只能改一个词，不能解决可读性；全量修改内部 demo ID 会破坏历史和授权。采用页面路径+公开数据源名称，在唯一地址边界解析并规范化；Next 精确 rewrites 复用同一工作台，不建立第二套页面状态。视觉保留既有构图，仅重做品牌图标、图表编码与图例配色。

## 验收
路由往返、旧链接迁移、歧义输入拒绝、数据源隔离；真实浏览器 320–1440px 下的浏览与 AI 往返、深链刷新和图表；类型、相关测试与生产构建；Linux 候选健康、静态资源与权限；切换后公网可访问且线上镜像 revision 对应源码。
