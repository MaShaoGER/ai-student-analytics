# MVP 固定问题与基准

固定问题先映射为受控的 `AnalysisPlan`，暂不让模型自由生成 SQL。下面 10 条覆盖首版 3 个指标、2 个维度和 3 种展示方式；基准值来自 `data/sample/`。

这些基准同时维护在 `lib/analysis/golden-cases.ts`，测试会逐条执行 DuckDB 查询并检查完整结果、样本数和 ±0.01 数值容差。

| 编号 | 固定问题                         | 指标     | 维度 | 图表   | 最高分组基准  |
| ---- | -------------------------------- | -------- | ---- | ------ | ------------- |
| 1    | 哪门课程平均成绩最高？           | 平均成绩 | 课程 | 柱状图 | AAA / 79.67   |
| 2    | 比较各课程平均成绩。             | 平均成绩 | 课程 | 柱状图 | AAA / 79.67   |
| 3    | 各学期平均成绩如何？             | 平均成绩 | 学期 | 折线图 | 2024J / 73.67 |
| 4    | 哪门课程学习活跃次数最多？       | 活跃次数 | 课程 | 柱状图 | AAA / 186     |
| 5    | 比较各课程学习活跃次数。         | 活跃次数 | 课程 | 柱状图 | AAA / 186     |
| 6    | 各学期学习活跃次数如何？         | 活跃次数 | 学期 | 折线图 | 2024J / 331   |
| 7    | 哪门课程完成率最高？             | 完成率   | 课程 | 柱状图 | AAA / 100     |
| 8    | 比较各课程完成率。               | 完成率   | 课程 | 柱状图 | AAA / 100     |
| 9    | 各学期完成率如何？               | 完成率   | 学期 | 折线图 | 2024J / 83.33 |
| 10   | 用表格查看课程平均成绩和样本数。 | 平均成绩 | 课程 | 表格   | AAA / 79.67   |

数值容差默认 ±0.01（展示值已经四舍五入到两位），所有分组必须满足最小样本阈值 3。

## 排序约定

学期折线图默认按分组维度升序展示，当前学期编码的顺序为 `2024B → 2024J`；上表的“最高分组基准”不代表折线图的第一行。课程比较和其他展示方式默认按数值降序，同值时按分组名称升序。

页面手动分析、固定问题和自然语言计划统一使用 `createPlan` 创建默认排序；显式传入 `sort` 时，查询尊重 `by` 和 `direction`，排序后再应用 `limit`。未来新增学期编码时须核对其字符串顺序是否仍对应时间顺序。

## 边界回归 B01–B10

以下场景维护在 `lib/analysis/boundary-cases.test.ts`，与 10 个正常 golden cases 分开计数：

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| B01 | 用客户端文件路径代替数据集 ID | Zod 校验拒绝，不读取任意路径 |
| B02 | 非白名单指标、分组维度或图表类型 | Zod 校验拒绝 |
| B03 | 指标与聚合方式不匹配 | Zod 校验拒绝 |
| B04 | 重复分组维度 | Zod 校验拒绝 |
| B05 | 行数限制为 0、101 或非整数 | Zod 校验拒绝 |
| B06 | 非法筛选字段、操作符或值结构 | Zod 校验拒绝；`eq` 只接收非空字符串，`in` 只接收非空字符串数组 |
| B07 | 筛选值含 SQL 注入字符串 | 按字面值查询并返回空结果；包含单引号的合法课程名仍可查询 |
| B08 | 分组不足 3 名不同学生 | 成绩、完成率和活跃次数均不展示该分组；重复活动行不增加学生数 |
| B09 | 数据集文件缺失 | 返回明确的数据源不可用错误 |
| B10 | 问题未说明分析指标 | 结构化输出要求澄清时抛出 `AIClarificationError`，不产生查询计划 |

这些是规划器与分析引擎的函数级回归：SQL 场景使用真实 DuckDB 和隔离的临时虚构 CSV，澄清场景注入结构化模型输出，不调用线上模型。HTTP 错误码、真实模型的澄清准确率以及浏览器交互需另行验收。
