# ADR 0005：正式界面采用单一产品设计系统

- 状态：采纳，2026-10-23
- 规格：[产品界面重构](../design/product-interface-system.md)

## 决策

根布局仅加载一套正式产品样式：语义主题、通用控件、应用壳与按领域分开的页面布局。组件使用统一令牌和 CSS Modules，不再以主题祖先类追加整套覆盖。导航和账号操作由 `WorkspaceChrome` 提供，业务状态继续由原有工作台管理。

## 背景与取舍

用户要求从多轮局部修改转为完整产品设计。原先工业主题、玻璃材质与组件特例同时影响同一界面，难以确定一个控件的真实样式来源。继续引入带预设皮肤的大组件库会增加迁移和样式映射，而现有原生控件与分析组件可以沿用。

因此本轮不增加 UI 依赖，先完成布局、层级、控件状态和样式归属的统一。后续复杂控件若确有需求，可引入无预设样式的交互基础组件，并接入现有令牌。旧玻璃文件与光学实现保留，退出正式页面加载，避免覆盖上一轮尚未提交的工作。

## 后果

- 统计与分析业务保持现有接口；数字直接展示准确值。
- 主题切换即时完成，避免全屏过渡拦截下一次操作。
- 桌面、平板与窄屏共用导航语义，移动布局和弹层在同一组件内维护。
- 新样式必须归入现有责任文件或组件，不能通过根布局不断追加主题补丁。
- 既有 Rare UI 改编组件继续保留来源和许可证，不将其归为本轮原创实现。
