# AI 对话体验预览

## 路由与定位

- 预览路由：`/preview/ai-experience`
- 数据文件：`app/preview/ai-experience/demo-data.ts`
- 用途：展示 AI 对话中的课程比较、澄清、单学期结果、活动关联探索、部分完成和错误状态。
- 页面组件：`app/preview/ai-experience/experience-client.tsx`；样式：同目录 `preview.module.css`。
- 打开即展示一轮完整的课程比较，可以直接操作；“从头体验”播放当前场景，侧栏切换三个预设场景。

## 数据边界

预览只使用 `demo-data.ts` 中预设的固定数据。页面不调用 `/api/chat` 或其他业务 API，不查询数据库、当前数据源或当前所选课程。开发环境仍会加载 Next.js 页面资源并建立热更新连接。

所有数值都是界面演示材料，并非当前统计查询结果。场景、答案、范围说明和风险提示会同时在界面上标注这一边界。

## 固定口径

| 项目 | 固定值 |
| --- | --- |
| 课程 | Web 前端开发 |
| 比较学期 | 2024J → 2025J |
| 平均分 | 72.72 → 69.65 分 |
| 均分变化 | -3.07 分 |
| 有效样本 | 199 → 200 |

- `compare` 和澄清后的完整课程比较共用上述均分、变化和样本数值。
- `term` 只展示 2025J 的课程范围、69.65 分和 200 个有效样本；入口与文档保留 72.72 → 69.65、-3.07 的完整比较口径。
- `term` 没有同单位的前后序列，因此 `charts` 为空；课程比较使用 1 张同口径前后比较图。
- `activity` 提供课程均分及学习活动参与率两张图，同一时间展开一张。两个图表的观察窗口分别说明，不描述为个体配对、相关性检验或因果结论。
- `partial` 保留已经可用的课程比较结果，状态为 `partial`，活动关联标为未完成。
- `error` 没有 `DEMO_ANSWERS` 条目，显示失败、已完成步骤和重试入口，重试后播放可恢复的课程比较。
- 指标和正文引用使用明确的事实 ID 绑定，点击打开本轮依据并定位；图表与表格沿用同一份数据。
- 原样复用正式对话的 `ExecutionSteps` 及已改编的 Rare UI 状态组件；本预览没有复制新的第三方源码。来源范围与版本继续见 [第三方说明](third-party-notices.md)。

## 场景与动作

| 场景 ID | 动作 | 入口问题 |
| --- | --- | --- |
| `comparison` | `compare` | 比较 Web 前端开发 2024J 和 2025J 的平均成绩 |
| `clarification` | `clarify` | 帮我看看成绩变化 |
| `relation` | `activity` | 学习活动与成绩之间有什么关联？ |

澄清入口提供两个候选：

1. `完整比较 2024J 与 2025J`，动作是 `clarify-result`。
2. `仅查看 2025J`，动作是 `term`。

## 操作清单

1. 打开 `/preview/ai-experience`，确认页面标出“固定演示数据”或同等边界说明。
2. 选择“课程前后对比”，检查 72.72 → 69.65 分、-3.07 分以及 199 与 200 个样本。
3. 选择“先澄清再分析”，确认原始问题是“帮我看看成绩变化”，并出现两个澄清候选。
4. 选择完整比较，确认显示 `clarify-result`；选择仅查看 2025J，确认显示 `term` 且没有图表。
5. 选择“活动关联探索”，确认活动图表标为演示，文案没有把关联写成因果结论，并出现“比较课程”追问。
6. 触发部分完成状态，确认课程比较可用、活动关联标为未完成，且 `completion` 为 `partial`。
7. 触发错误状态，确认失败记录和重试入口；点击重试得到比较结果。
8. 分析过程中停止，确认不会重新提交、不出现迟到结果，问题保留在输入框。
9. 回复期间回看历史，确认结果到达后仍保留位置，并出现“回到最新回复”入口。
10. 通过开发工具确认交互过程没有请求 `/api/chat` 或其他业务 API。
11. 测试浅深主题、动效开关、系统减少动态效果，以及 320px / 390px 窄屏。

## 用户确认与待办（2026-10-20，暂不实施）

用户在预览页批注后确认以下方向。本轮仅记录，预览代码和正式功能均暂不修改。

1. **保留当前整体布局。** 正式落地时，左侧目前的“预设对话场景”面板改为历史对话列表；对话历史按账号保存，不同账号隔离。用户已确认从最后一条消息更新后起算 10 天，继续对话会续期，单纯打开或切换展示不续期。不能将纯浏览器本地保存当作账号持久化和服务端清理。
2. **补充回答自动滚动的动画与阅读落点。** 当前预览在跟随状态中直接设置 `scrollTop = scrollHeight`，结果到达时会跳到内容末尾。后续调整为可打断的平滑跟随，结果出现时优先保持回答开头／正在阅读的位置可见；用户回看时保持位置，并提供回到最新回复的入口。继续尊重动效开关和系统减少动态效果。
3. **正式接入现有图表系统。** 当前预览的 `PreviewChart` 是轻量 SVG／表格演示。正式版本沿用 `ChatResponse.artifacts` / `ChatArtifact`，复用 `AnalysisResultView`、`ConversationToolResult`、成绩分布以及 `AnalysisChart` / `StudioChart` / 学科关联和全景渲染组件，保留既有统计口径、事实引用与各类图表已有交互。展开容器后处理图表尺寸更新；历史恢复按数据集权限和版本核对结果可用性。

4. **按数据语义选择图表／表格。** 同时接入现有表格系统，根据问题意图、指标单位、时间顺序、样本和分母等选择默认形式。图、表、文字与数字依据共用真实结果；不合适的形式明确回退，纯展示切换不重新调用 AI。

本节状态：已记录并完成正式接入规划，尚未实施功能。分期、展示规则、账号历史和验收见 [AI 对话体验正式接入规划](ai-conversation-experience-roadmap.md)，另一窗口可使用 [开工指令](ai-conversation-experience-build-prompt.md)。

## 已执行验证

2026-10-20 本地验证：

- 类型检查与新文件 Prettier 检查通过；Next.js 运行时 `compile_route` 返回空问题列表，`get_errors` 无配置或浏览器会话错误。
- 浏览器通过课程比较、图表／表格切换、数字依据定位、单学期追问、澄清后分析、多图单独展开、部分完成、失败后重试、停止保留问题、回看不抢滚动位置。
- 修正停止按钮在切换成发送按钮时可能触发表单默认提交的问题，复验停止后只有原来的停止记录、无新的运行轮次。
- 1280px / 1512px 桌面及 320px / 390px 浏览器窄屏检查，页面无横向溢出；触屏仿真输入字号 16px，输入区处于可见底部。
- 交互期间捕获的网络请求没有业务 API 请求；页面资源／开发热更新不计为 AI 调用。
- 浏览器窄屏与触屏仿真不替代手机真机和软键盘验收；本轮未执行生产构建或外部 AI 语义评测。

## 正式接入后的边界（2026-10-20）

正式登录工作台的「一句话分析」已复用当前布局方向，并接入实际执行、账号历史和原有图表系统，见 [正式体验说明](ai-conversation-experience.md)。本预览继续使用固定片段，不创建正式历史、不证明模型语义能力。预览中 72.72 → 69.65 的学期标签仍是演示口径；当前 CSV 的对应真实学期为 2025B → 2025J，正式结果不会照搬预览标签。
