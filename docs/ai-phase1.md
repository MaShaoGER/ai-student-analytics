# AI 第一阶段：连续对话与原生分析结果

2026-10-17，本地分支 `codex/ai-功能完善`。入口仍为“一句话分析”，保留原指标、图表工坊、报告、数据及管理入口，旧 `/api/ask` 继续兼容。

## 能力

- 普通交流、指标说明、分析方法讨论与需要澄清的问题均作为正常对话回复，不要求每句话都变成查询。
- 查询三个已接入指标：平均成绩、学习活跃次数、课程完成率；支持课程/学期分组、精确课程与学期筛选、排序和返回条数。
- 调用已有成绩分布查询，支持课程、学期和 2/5/10 分档，前端使用原生热力表与数值表；表头随分档变化，搜索只筛选当前结果。
- 连续追问继承课程、学期、指标和展示参数；明确的“改成表格”“按10分一档”等无需调用模型。模型遗漏或返回空学期不能静默扩大查询范围；明确“全部学期”等请求才清除相应筛选。
- 保留原有柱状/折线/环形/树图/雷达/气泡及表格组件，继续执行统计语义检查：均分、完成率不作构成占比，不合适的视图说明原因并回退。
- 对话页采用整页滚动，标题和数据源随消息滚动；顶部导航、左侧菜单与靠近底部的悬浮输入框保持可用。每轮结果保存在对应回复中，同一对话最多展开一张，收起或重开历史图表不会重新查询；双方使用独立身份图标。
- 支持停止回复、开始新对话；查询失败保留上次成功的数据。解读失败或预算不足时保留本次实际查询结果和程序计算的摘要。

## 数据与对话边界

`POST /api/chat` 接收问题、数据源、最近对话和上次查询意图。历史是非可信上下文；不接收系统角色，不相信客户端提交的数字。当前问题最长 500 字，模型上下文最多 12 条消息，每条最多 3,000 字；请求体上限 150,000 字节。界面最多保留 40 条消息，仅存在当前页面内存，刷新、切换数据源、退出或新对话会清除。

模型先选择回复、澄清、指标查询或成绩分布。后端重新验证结构化意图，通过已有参数化/固定统计 SQL 执行，不接受模型 SQL 或模型生成的表格数据。规划只接收可用课程/学期标签；结果解读只接收查询后的群体聚合，不含学生标识、原始记录或 SQL。

数值摘要由程序直接计算，包括返回范围、样本数、最高/最低及其差值，或分布峰值区间与占比；“最高/最低”明确限定为返回分组，跨学期成绩使用人次。AI 解读仅提供解释限制、待验证的原因和后续分析方法；解读正文中的阿拉伯数字/百分比被校验拦截，以免重新生成统计结论。自然语言解释仍需结合数据核对，不能作为因果、显著性或个体判断依据。

沿用登录与同源校验，`/api/chat` 和 `/api/ask` 共用账号限流。DuckDB 查询上限、取消、小样本抑制等沿用既有实现。规划与解读最多两次模型调用，共用同一次请求的费用上限；小时/日/月预算、并发预留与实际用量结算继续有效。不会自动重试收费调用。普通知识问答在数据暂不可读时仍可回复。

审计仅记录用户、数据源、有效分析计划、阶段、耗时、结果条数及安全错误摘要；不持久化问题、对话、模型正文或结果明细。成绩分布审计沿用现有记录结构，不伪装成均分计划。
