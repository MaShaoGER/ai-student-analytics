# AI 回答完整性与数字含义修正

日期：2026-10-19。本轮在 `codex/competition-phase2` 本地实施，未推送或部署。

## 问题与实现

真实浏览器提问“比较2025B与2025J各课程平均成绩，哪门课程下降最多，下降多少？”时，统计已算出 Web前端开发下降 3.07 分，正文却只剩“其余多数课程在两个学期间的成绩呈上升趋势”。原实现仅在整段回答被过滤为空时重试，因此遗漏核心答案的残余描述仍会被接受。

- 输出增加完整性检查：明确的数值问题需要引用计算事实；最大降幅问题需同时覆盖对应课程与降幅；最高/最低分组问题需要对应分组和指标值。检查只约束回答，不选工具、不安排固定执行顺序。
- 学期比较拆分前期均分、后期均分、有符号变化、正数降幅及两期样本人数，每条带课程、学期、指标和数值角色。原“学期比较结论”含多个数字，改为 `numeric: null`；引用它时输出完整计算结论，不再用一个数值代表整句。
- `FactRef.semantic` 是可选字段，旧结果仍可展示。新增常见错配检查，拦截降幅/分差充当均分、课程/学期错位及样本人数替代降幅等情况。失败仍只做一次预算内修正；重写仍不完整则返回程序生成的事实并提示原因。
- 比较结果保留参照学期，`resultId` 纳入前后两期。更换参照学期会产生不同结果标识，表格/图表切换保持同一标识。
- 独立评测从 `data/sample/student_outcomes.csv` 逐学生复算两期均分和最大降幅，检查回答课程、方向、降幅和已提及分数的前后含义；不调用生产端的完整性校验函数来判定自身是否通过。

## 完成边界

这些检查覆盖明确的数值问法和常见语义错配，不证明任意自然语言解释都正确。知识类解释、未调用统计工具的直接回答、缺勤上下文、长会话、持久化、统一报告以及硬失败 usage 继续单独处理。原子事实目前以学期比较和聚合极值/分差为重点，其他图表仍可能只有概括事实。指标语义替代尚未由本轮彻底解决。
