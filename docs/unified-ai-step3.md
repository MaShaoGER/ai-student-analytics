# AI 统一对话第三步：自然回答与界面精简（实施记录）

实施日期：2026-10-19。分支：`codex/competition-phase2`。本轮实施[统一对话路线图](unified-ai-workflow-roadmap.md)的**第 3 步「输出自然回答并精简界面」**；同轮完成的第 4 步（请求级用量、评测重建与本地验收）见[第 4 步实施记录](unified-ai-step4.md)。改动只在本地，未推送、未部署。

第 1 步已完成的部分（移除模式切换、「数字从哪来」默认折叠）不重复计入本轮。

## 本轮做了什么

### 1. AI 自然回答 + `factId` 绑定

- 工具循环的最后一轮模型文本不再被丢弃。每个工具返回新增 `facts: [{ factId, text, value, unit }]`（本轮已计算的结果事实，含缺勤与学期比较结论），模型被要求用 `{{factId}}` 占位符引用数字，而不是自己写数值。
- 新增 `composeBoundAnswer()`（`lib/ai/unified.ts`）：
  - 按句拆分；**只接受占位符**：含未知占位符的句子丢弃；占位符之外出现任何数字（ASCII/全角数字、中文数字如"三成/十门"）也整句丢弃；
  - 有效占位符替换为**已核验的数值 + 单位**（例如 `79.42分`），放在模型自己的句子里，并收敛模型重复写出的单位（`79.42分分` → `79.42分`）；Markdown 粗体标记会被清理；
  - 全部句子被丢弃时，先做**一次修正重试**（见下）；重试仍无法绑定或终轮为空，则回退事实模板并给出 warning；
  - 部分丢弃时保留可用句子并 warning「部分解释含未核验数字或无效事实引用，已省略这些句子」。
- **为什么不做"逐数字对账"**：早期实现允许"模型自己写的数字只要能在本轮任意事实里找到就保留"，独立审查用真实评测答案证明它会把**高低差 21.77 当成某课程平均分 21.77** 仍判通过（数字命中 ≠ 归属/单位/符号正确）。现在改为占位符唯一来源：数字必须由程序从对应 `FactRef` 填入。代价是模型不遵守占位符时句子会被丢弃，因此加了下面的一次修正重试。
- **一次修正重试**：首次绑定失败且本轮有事实时，把事实摘要与"只能用占位符"的明确指令追加给模型再请求一次（同一请求预算内，最多一次）；成功则用修正后的回答，失败则回退模板。真实评测中比较、图表、缺勤场景因此保住了自然回答。
- 回答来源说明（`planning.rationale`）继续按实际路径区分：工具结果 / 知识引用 / 知识不足 / 直接回答（数字未核验）/ 无结果。
- 失败或部分完成（`failureCode`）仍使用模板，避免把部分结果写成完整结论。

### 2. 提示词与工具说明（依据真实评测结果迭代）

真实模型评测暴露出三类行为问题，已在提示词层修正：

- **缺勤问题**：模型曾逐门课程调用 `absence_stats`（6 次后触发工具上限）并顺带查活动量。现在工具说明明确「不传课程即可一次拿到范围内全部课程，不要逐门调用；缺勤只能用 `absence_stats`，不得用活动量聚合替代或补充」。
- **定义问题**：模型曾凭记忆直接回答"完成率和出勤率有什么区别"。现在要求定义、规则、"是什么/有什么区别/如何计算"必须先调用 `search_knowledge`，检索不到就如实说明。
- **评价性结论**：模型曾只写"理工类偏低、文科较好"这类无法核对、且不用具体课程名的概括。现在要求"最好/最低/偏高/偏低/最多/最少"等评价必须紧跟至少一个本轮 `{{factId}}`，并使用数据中的课程/学期全名；同时要求用完整句子，不要只写标题或空列表。
- **范围不足先追问**：缺少课程、指标或参照学期、且无法从已确认上下文推断时先 `clarify`；同时说明 aggregate 不传筛选等于全部课程/学期，是合法范围，避免把可回答问题变成追问。
- **格式与去重**：要求用完整中文句子、不要 Markdown 加粗/标题/列表；占位符已含数值和单位，不得重复写。

### 3. `aggregate` 工具支持展示参数

`aggregate` 新增可选 `view`（`bar`/`line`/`table`）、`sort`、`limit`，直接写入执行计划与上下文，使"用表格按课程名排序显示前 5 门课程平均成绩"一次调用即可出表；不再需要先出图再"改成表格"。默认值保持不变（学期维度折线、其他柱状；按值降序；limit 100）。

### 4. 输入区可收起并保留草稿

`components/ai-conversation.tsx` + `ai-conversation.module.css`：

- 输入区 header 增加「收起输入区 / 展开输入区」按钮（`aria-expanded` / `aria-controls`、`title`），回复中禁用收起，保证停止按钮可达。
- 收起时隐藏输入框、发送/停止、推荐问题、新对话与筛选 chip 行，保留一条紧凑栏「输入区已收起，草稿已保留：「草稿前 24 字…」」；展开后焦点回到输入框且不滚动页面。
- 草稿仍由父组件持有，收起/展开不改动任何消息、上下文、附件或结果展开状态；收起期间若从对话区触发回复，会自动展开以保留停止入口。
- 390px 布局收紧、无横向溢出；按钮 ≥32px、键盘焦点可见；动效沿用既有 token 与 reduced-motion 规则。

## 已知限制

1. **占位符保证数字来源，不保证语义位置正确**。数字一定来自对应 `FactRef`，但模型仍可能把某条事实放到错误的句子里——最终真实评测中观察到"以最低分（21.77分）垫底，两者相差 21.77分"（21.77 实为高低差）和"从 2025B 的 3.07分 降至 2025J"（3.07 实为降幅）这类语义错位。协议检查能发现"数字无出处"，但发现不了"有出处却用错位置"；后者需要人工/更强评测，路线图也明确"基础检查不声称能证明整段解释正确"。
2. **自然回答依赖模型配合**。模型完全不用占位符时句子会被丢弃，修正重试仍失败则回退事实模板（如实、但不自然）；真实评测中 follow-up 等场景出现过只剩定性句或模板回退。
3. **知识/定义类回答仍以引用片段呈现**（沿用第 1 步行为），没有做成"AI 解释 + 事实绑定"；本轮自然回答只覆盖工具结果路径。
4. **无工具的直接回答**仍是模型口头文字；数字只加"未经统计核验"warning，不做数值核验（与第 1 步一致）。
5. `composeBoundAnswer` 按句切分，不解析完整 Markdown 结构；已清理粗体标记并要求完整句子，但列表/标题类输出仍可能退化为短句。
6. `aggregate` 的展示参数限定 `bar`/`line`/`table`；饼图/雷达图等仍走高级图表工具。
7. 真实模型评测为小样本、单模型（qwen3.7-flash）、单数据源（`data/sample`）；提示词与评测检查项都在本轮迭代过，不能当作泛化准确率。
