# 后台管理首期使用与存储说明

本轮实现范围为[路线图](admin-management-roadmap.md)阶段 0–5。Excel/CSV 上传导入、组织树、自定义角色、多租户和课程/班级级授权留待后续。

## 使用

管理员登录后从“设置 / 系统管理”进入系统总览、账号管理、数据集管理、AI 配置和操作日志；本人改密保留在“我的账号”。账号管理页同时说明预设角色权限。

- 管理员管理全站账号、数据源和 AI；业务查询仍受数据集启停和文件可读状态限制。
- 教师／分析人员（存储值 `user`）查看获授权数据、调用 AI、导出聚合结果。
- 只读人员（`readonly`）查看获授权的标准聚合图表，包括确定性的 POST 统计；不能调用 `/api/chat`、旧 `/api/ask` 或固定问题的本地降级，不能使用产品的 CSV/HTML 导出。
- 账号名创建后不可修改，显示名称、普通/只读角色、数据集授权和启停可编辑。管理员保护沿用现有规则，此入口不能提升为管理员或停用、重置、撤销受保护管理员。
- 新建账号必须显式选择授权；空选择表示没有可查询的数据。账号启用不会恢复已撤销的会话。
- 重置密码会撤销该账号的旧会话，并只在该次响应展示临时密码。使用临时密码登录后必须先改密，随后重新登录。列表和日志不返回临时密码。
- 数据集停用不删除文件，管理页仍可查看和恢复；“已停用”“未授权”和“文件缺失或不可读”分别处理。目录版本为声明版本，并非内容哈希。

导出按钮的权限限制不能阻止用户复制或截图已允许查看的内容，权限撤销也不能删除已下载到设备的副本。

## 访问边界

请求身份来自 HttpOnly 会话。每次请求读取最新账号角色、强制改密标志和数据范围；客户端角色、历史消息和结果引用不授予权限。

画像只查询当前账号获授权、启用且文件可用的数据源，空授权返回空数组。缓存键包含数据源范围和文件签名，返回前仍需通过当前授权。未授权账号无法获取课程/学期目录或画像明细；已停用/不可用的获授权目录项只返回状态和空表；enabled 表示业务开关，available 只表示源文件可读，两者独立。

标准分析、分布、关系、全景、工坊、新旧 AI 路由均使用统一检查。业务执行建立服务端 AsyncLocalStorage 授权上下文，实际 DuckDB 查询、AI 执行入口、工具和供应商调用再次检查。CLI/评测属于受信任服务端调用，不通过客户端创建此上下文。

前端在账号切换和权限状态更新时清理结果与对话；重新聚焦和定期校验捕捉其他会话中的变化。后端授权始终是安全边界。

## 状态版本与迁移

沿用 `APP_STATE_DIR`（默认 `records/system`）和已有跨进程锁、临时文件、fsync、原子重命名机制，不引入数据库。

- `accounts.json`：版本 1 → 2。保留用户 ID、账号、哈希和会话，新增 `datasetIds`、`mustChangePassword`；旧普通账号在版本迁移时一次性获得原先的 `demo` / `oulad` 范围。版本 2 的空授权保持为空，后续启动不会补权。`admin` / `user` 兼容，新增 `readonly`。
- `datasets.json`：版本 1，登记两个固定 ID 和启用状态。文件路径由服务端受控映射解析。默认目录状态启用；实际可用性逐次检查必需文件存在、可读且为文件，不作内容质量保证。
- 管理日志嵌入对应状态文件的 `__adminAudit`（版本 1）。账号、数据集、AI 配置和分析设置与其审计事件同一事务落盘，日志写入失败应拒绝变更；不会异步写入后忽略错误。
- 管理事件仅存动作、目标 ID、操作者 ID、时间、白名单变更摘要、结果和受控错误码。无密码、令牌、密钥、对话正文或学生明细。
- 每个管理日志来源保留最多 5,000 条、180 天；在后续管理变更写入时对管理日志执行有界保留，不在首次启动清理已有分析记录或费用记录。备份保留策略独立管理。
- 新分析记录增加服务器生成的 `requestId` 和显式 `outcome`（成功/部分完成/失败）；旧记录不回填虚构身份或结局。既有 UTC 时间不改写。

升级前通过现有恢复工具在停写条件下备份完整 records 和独立保管的 `APP_SETTINGS_KEY`。需要回滚时恢复同一备份中的账号、授权、配置、费用和日志；不要只拷贝单个账号文件。损坏或未知版本状态不能自动重置为初始账号。

## 接口和统计口径

管理接口都要求管理员，修改还要求同源 Origin，响应禁用缓存。

| 接口 | 用途 |
| --- | --- |
| `GET /api/admin/users` | `q`、`role`、`disabled` 筛选和 `page` / `pageSize` 分页 |
| `POST /api/admin/users` | 显式角色/授权创建，或 `action: reset-password / revoke-sessions` |
| `PATCH /api/admin/users` | 按 ID 更新显示名称、普通/只读角色、授权或启停 |
| `GET /api/admin/datasets` | 全部登记目录和可用性 |
| `PATCH /api/admin/datasets` | `{ id, enabled }` 启停 |
| `GET /api/admin/overview?window=today\|7d\|30d` | 有依据的全站概览 |
| `GET /api/admin/logs` | 时间、操作者、动作、结果筛选和有界分页 |

[概览及日志契约](admin-stage4-api-contract.md)列出返回字段和覆盖范围。时间窗日界线按 `Asia/Shanghai`，持久记录保存 UTC。业务请求按 requestId 去重，与模型调用分开；无 requestId 的旧记录单独披露，不能伪造关联。旧记录缺字段或坏行、读取截断必须有覆盖说明，不能当作零业务。费用和用量来自已有结算记录，费用为估算，不能当供应商账单；连接测试和评测如不能区分，说明可能混入。当前不会展示无依据的在线人数、持久报告总数或教学效果提升。

画像与图表 GET 没有独立业务审计时，不计入有 requestId 的分析请求统计；分析请求覆盖标准 `/api/analysis`、旧 `/api/ask` 和 `/api/chat` 的已记录请求，不代表 HTTP 总流量。

## 验证

验收使用隔离账号、临时状态和编译目录，不改实际 AI 设置，不调用付费供应商。执行类型、单元/路由、HTTP、重启、备份恢复、生产构建和真实浏览器验证；最终结果见 `DEV_STATE.md` 顶部交接和本轮验收记录。原有 AI 真实语义评测失败项独立保留，不因后台完成而改判。
