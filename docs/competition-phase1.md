# 赛事第一阶段：基础准确性与评测

实施日期：2026-10-19。工作分支：`codex/ai-home-preview`，基于 `12800ff`。本轮保留原有预览页和用户文件，同步 README 与续接记录；仅作本地提交，未推送或部署。

## 统计说明与导出

- 普通分析的结果和范围元数据复用同一份受筛选的数据源，支持模拟数据和 OULAD 的成绩、活动量、完成率。
- 统计周期列出实际匹配的学期及请求中的课程/学期筛选。零条源记录标注“无匹配记录”；有记录但未达到样本阈值时保留其实际学期。
- 小样本过滤分组数由 DuckDB 按同样的维度、筛选和去重人数计算，发生在显示 LIMIT 之前。不会把超出显示数量的合格分组计为隐私过滤，也不会将跨学期的同一学生重复计为多人。
- 空结果保留 HTTP 422 / `NO_DATA`，响应附带已计算的 plan/result，工作台可据此展示真实空结果和报告，避免沿用旧结果。
- 页面和 HTML 报告共用过滤说明。旧快照的过滤数为 null 或未记录时显示“无法确定”，不冒充已测得的 0。
- CSV 带有过滤说明；空结果也保留一行元数据，分组、指标值和参与人数列为空，不伪造零值。空结果可生成、预览、下载报告；报告保留统计范围、阈值和 SQL。

## 密钥与地址绑定

- 保存密钥时记录 URL origin（协议、域名、有效端口）。更换 origin 而未重新填写密钥时，接口返回 HTTP 400 / `AI_KEY_REENTRY_REQUIRED`，旧配置不会部分更新。
- 同一 origin 的模型、协议、预算或路径更新可以继续使用原密钥。尾斜杠、域名大小写和默认 HTTPS 端口不构成新的 origin。
- 旧密文兼容现有地址，下一次成功保存时补记绑定；已有明确绑定却不匹配时停止使用密钥，不回退到环境变量。
- 环境变量密钥只可用于 `OPENAI_BASE_URL` 指定的 origin（未设置时为 OpenAI 官方 origin）；旧版自定义地址没有保存密钥时，不会误用官方环境变量密钥。
- SDK 总是显式收到最终基础地址，避免 SDK 自行读取 `OPENAI_BASE_URL`，将保存密钥发往其他地址。
- 本轮只修改代码及隔离测试配置，没有修改用户的实际密钥、单价、预算或线上设置。

## 扩展评测

新增 12 个场景、15 轮对话：连续追问、筛选冲突、图表选择、数值核对各 3 个场景。实际返回的 context 和历史用于后续追问。数值期望来自固定 golden CSV，包含 79.67 分、66.67% 和 186 次等独立基准，并核对去重人数与实际执行范围。

报告区分规划、查询、展示三个阶段；依赖的前一阶段失败时记 blocked。模拟模式使用注入的规划输出、真实 SQL，并禁止网络，不能作为真实模型准确率证据；真实模式另外运行、另外出报告。命令与报告字段见 [AI 评测说明](ai-eval-cases.md#赛事第一阶段扩展2026-10-19)。
