# 正式 AI 对话体验

2026-10-20。正式入口为登录工作台后的「一句话分析」。不是独立演示业务；`/preview/ai-experience` 保留为固定片段的无 AI 调用体验回归页。

## 使用

- 左侧账号历史可新建、分页、打开和删除，并可向左折叠。历史自最后一条真实消息保存后保留 10 天，浏览和切换形式不续期。窄屏通过「历史对话」抽屉进入。
- 输入问题后显示现有真实执行步骤，步骤详情默认折叠，最终按结论、图表或表格附件、分析依据和分析方式排序。SSE 传步骤和最终结果，不模拟逐字回答。
- 附件只开放数据结构允许的展示。类别默认横向条形；至少三个真实有序学期点用折线；两期比较用现有哑铃图；多字段精确值及超过 40 类的结果默认表格。组成、分布、关系和流转图必须有对应可信结构。
- 「图表／数值表」等按钮只修改本地展示，保留 resultId 和 factId，不请求模型、不重算、不更新历史。输入「换成表格」等纯展示追问会保存新一轮消息，同时复用已有聚合快照；这属于实际消息更新，会续期。
- 清除范围仅影响后续追问；服务端以 resetContext 建立上下文边界。课程、学期或指标变化继续进入原有统计／AI 工具流程，不将历史数字当作当前证据。
- 长回答整体到达时落到回答开头。滚动、触摸、拖动滚动条或键盘阅读可打断跟随。右侧刻度可跳到开头、提问轮次与最新内容；键盘触发即时定位。附件加载和展开不会强行跳到底部；回看时尽量保持已有阅读锚点。
- 动效开关和系统减少动态效果都会取消滚动位移动画。输入法组合态 Enter 不发送，输入焦点不随回复移动；执行状态由原有专用提示宣读，正文不作为不断播报的实时区域。
- 历史结果显示生成时间、结果契约版本及数据／指标声明版本。声明版本不等于内容指纹；历史数据可能已更新，继续进行分析时重新查询。
- 若分析已完成但保存失败，文字和结果继续显示，通过「重试保存到历史」仅重试持久化；不再次调用模型。进程内待保存结果最多保留 5 分钟、20 条，重启会丢失并明确提示。

## 真实数据与预览的差异

当前 `data/sample/student_outcomes.csv` 中，「Web前端开发」的 **2025B → 2025J** 为 **72.72 → 69.65 分**，变化 **−3.07 分**，有效样本分别 **199 / 200**。2024J 实际均分为 **69.99 分（200 样本）**。预览固定片段的 2024J 标签不能作为实时统计证明；本轮没有改写原始数据去迎合演示。

比较结论、数值表、哑铃图和数字依据读取同一份计算结果。新增 studio 比较事实适配保留前后值、变化与两期样本，不将群体差异解释为个体进退或因果。

## 接口与代码边界

- `lib/analysis/presentation-policy.ts`：纯语义规则与已有 artifact 适配，无查询与模型调用。
- `components/conversation-artifact.tsx`：校验展示、解释回退，渲染插槽继续调用原有 `AnalysisResultView`、`ConversationToolResult` 和成绩分布表。
- `components/workspace.tsx`、`components/ai-conversation.tsx`：原有正式请求流程、停止、重试、引用和新布局。
- `lib/conversations/`：账号桶、原子 claim/finish/fail/stop、TTL、快照字段校验和清理。详见 [历史存储与部署](ai-conversation-storage.md)。
- `lib/ai/conversation-session.ts`：可信上下文加载、重放、仅展示追问、保存和有限保存重试缓冲。
- `/api/conversations` 列表／创建，`/api/conversations/:id` 详情／删除，`/api/conversations/:id/stop` 停止；`/api/conversation-save` 仅重试已计算结果保存。
- `POST /api/chat` 正式客户端提交 `conversationId + turnId + expectedRevision`，三者须同时出现；客户端 history/context 在此模式下被服务端历史覆盖。保留无会话标识的旧接口兼容路径；旧接口不创建账号历史。

新问题先原子领取轮次，模型与统计在锁外执行，最终保存再次检查状态；同轮同摘要不重复执行，不同摘要和过期修订拒绝。同进程停止立即中断，其他进程约每秒检查持久状态后中断；被删除、过期或停止的迟到结果不能复活。断线不保证立刻送达取消信号，重放或打开历史会显示实际终态，服务不会自动再次调用 AI。

## 本地检查

```bash
pnpm typecheck
pnpm test
pnpm test:api
pnpm test:recovery
node scripts/verify-ai-conversation-browser.mjs
NEXT_DIST_DIR=.next/ai-experience-build pnpm build
```

浏览器脚本需要已安装 `agent-browser >= 0.31.1`，自动启动 3220 端口的隔离 Next 服务、临时账号和空模型配置，并使用 `data/sample`。长回复 fixture 仅在测试浏览器装饰接收到的 SSE 正文，明确标注，不修改正式业务或生产数据。报告和截图位于 `output/ai-conversation/`；触屏为浏览器仿真，不等于手机软键盘真机验收。

构建期间请使用独立 `NEXT_DIST_DIR`，不要删除运行中的 `.next`。浏览器脚本退出时清理自己的服务和临时账号，保留其他开发服务及工作区改动。
