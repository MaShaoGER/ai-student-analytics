# 学析台前端设计（2026-10-17）

## 主页激进动画风格（2026-10-18，预览分支 `test/ui-home-preview`）

- 只改主页，不动其它页面：学习全景每次挂载（登录、切换导航回到首页、浏览器刷新）播放一轮约 1.2s 的入场编排——眉题裁切擦入、标题 720ms 上浮、指标卡错峰入场、分区条横向擦出、右栏从右侧滑入、排行行与分布条错峰。安全/减弱动效开关与系统设置优先；键盘用户的交互反馈仍即时，入场动画作为数据呈现仍在切换时播放一次。
- 数字与刻度：真实指标数字 900ms 从 0 缓出计数（首次拿到数据、返回首页、切换数据源时重播），0–100 刻度条 1000ms 生长；加载阶段改为脉冲骨架条，不再出现大号破折号。排行分布条改为 `scaleX` 生长，切换指标时随行错峰重播。
- 图表：首页图表改为“分组逐柱生长”入场（760ms，每组间隔 32ms）；指标切换或数据源切换时图表整组重播而不是在无关课程间变形，图形类型切换带动画重绘。
- 主题切换：主页上以点击位置为圆心、700ms 的圆形揭示切换浅/深主题（View Transition API）；非主页与不支持该 API 的环境保持即时切换。
- 侧面板：主页的导航抽屉改为 460ms `--ease-drawer` 滑入 + 导航项 80–280ms 错峰，关闭 240ms；右栏 AI 卡与数据卡同样参与入场滑入。
- 控件统一：主页所有按钮 150ms 按压缩放 / 200ms 颜色状态过渡，统一使用现有 `--ease-out` 与 `--enter-ease` 令牌；侧栏、图表和画布动效仍遵循本机动效开关 `data-motion` 与系统减少动态效果。
- 验证（按用户要求收敛）：类型检查通过，`lib/analysis` 图表语义测试通过；隔离浏览器核对浅/深主题、桌面 1512×982 与手机 390×844，动画中无横向溢出（390 = 390），`prefers-reduced-motion` 下无运行中动画。录制动画演示：`output/playwright/anim/homepage-motion.mp4`（10.4s）与 `homepage-entrance.gif`。未运行生产构建、完整 HTTP 套件与真机。
- 隔离预览使用临时账号与 `/tmp/chuanzhi-preview-state`，未触碰真实 records、未推送或部署。

## 当前实装：直角工业编辑风

本轮交互细化：左侧工具栏承接品牌、主题、管理与账号操作，顶部保留业务主导航；窄屏导航贴着侧栏展开。全景和弦图共用低饱和学科分类色，关联带按两科渐变，列表和图上点击使用一致的选中/取消结果。弦图保留图形节点并平滑改变透明度，侧栏使用同方向进出；键盘和减少动态效果保持即时。成绩分布与学习节奏热力图分别服务成绩区间和周活动分析，按用户确认保留两者，只统一前者的色阶。

深色模式于 2026-10-17 按新参考调整为深蓝炭 `#16232a`、深海青绿 `#075056`、冷白 `#e4eef0` 与强调橙 `#ff5b04`；浅色原有色板保留。标题与数据档案底部增加 16px 四级同色变浅色带，不覆盖内容或改变数据含义。主图表、控件、浮层及独立 HTML 深色报告同步主题；本轮类型检查、18 项导出测试、主要文字对比度和 390px/320px 概览宽度核对通过，未进行完整发布验收。本次调整尚未提交。

两轮交互预览确认后，在 `codex/industrial-interface` 落实到项目。采用暖白、鼠尾草绿、炭黑、橙色，全部面板和控件保持直角；统一规范见 `.interface-design/system.md`，具体完成与验证范围见 `DEV_STATE.md`。

概览以橙色标识带、编辑式标题、真实指标刻度、炭黑图表和终端式提问构成对齐网格。沿用现有 Next.js/React/ECharts，不新增依赖；原分析、推荐问题、图表、导出、数据与管理能力保留。报告预览与独立 HTML 同步配色和直角。

动效限于操作反馈：导航指示线与图表更新 240ms，按钮 160ms，无环境循环。个人设置提供本机动效开关，键盘和系统减少动态效果即时响应。窄屏减少图表标签密度，完整数据保留在交互和表格中。

本轮按用户要求只执行定向检查：类型检查、25 项现有图表/导出专项与主要页面视觉核对；不代表完整发布验收。界面改版已在分析恢复提交 `3c614f1` 之后独立本地归档，未推送或部署。以下保留历史设计与验证证据，以本节为当前方向。

## 历史实装：柠檬黄双主题

用户在设计预览中确认后，创建 `codex/lemon-frontend` 并落实到登录、概览、分析/提问、数据、报告、系统管理和个人设置。保留现有能力和真实统计口径，不引入新的界面依赖。

- 浅色：背景 `#e9ebe3`、面板 `#f8f9f4`、正文 `#252820`；深色：背景 `#1a1b19`、面板 `#252623`、正文 `#f0f2e9`。品牌与主要行动统一 `#e6f436`。
- 顶部横向导航与浅/深主题切换分别包在共同的圆角背景内。浅深模式保存在本机，首次跟随系统；主题初始化脚本在绘制前应用外观，图表和报告预览同步更新。
- 桌面面板 32px、手机 24px，按钮和切换组为胶囊，工具按钮为圆形。概览为标题 + 三项真实指标，主图与明细在左，AI 入口、推荐问题和数据概况在右。
- 成绩蓝、活动紫、完成率青绿；每个普通分析块采用对应色族。超过 6 个分组的活动构成图、双指标气泡图可以多色。图表图例、选择和详情使用同一组令牌，并将 CSS Color 4 色值转换为 ECharts 能识别的颜色。
- 下拉保留原生 select 语义与键盘操作，支持 `appearance: base-select` 的浏览器使用圆角浮层、勾选和指标色选中态，其他浏览器使用原生回退。比较维度箭头固定在框内右侧。
- 可点击摘要卡上浮 3px；展示面板上浮 2px，阴影伪元素透明度 0.6。采用 300ms `cubic-bezier(.23,1,.32,1)`，阴影/发光以 opacity 过渡，避免持续循环。按钮柔光跟随品牌或所在指标；键盘和减少动态效果保留即时反馈。
- 推荐问题无静态阴影，文本可安全换行，“试着问问”的消息图标紧随标题。数据概况和主图入口使用一致的圆形箭头，AI 星形图标不再套圈。
- 报告预览跟随工作台外观；独立下载 HTML 使用浅色，打印强制浅色纸面，保留数值、样本、口径与 SQL。
