# 学析台前端设计（2026-10-17）

## 当前实装：直角工业编辑风

两轮交互预览确认后，在 `codex/industrial-interface` 落实到项目。采用暖白、鼠尾草绿、炭黑、橙色，全部面板和控件保持直角；统一规范见 `.interface-design/system.md`，具体完成与验证范围见 `DEV_STATE.md`。

概览以橙色标识带、编辑式标题、真实指标刻度、炭黑图表和终端式提问构成对齐网格。沿用现有 Next.js/React/ECharts，不新增依赖；原分析、推荐问题、图表、导出、数据与管理能力保留。报告预览与独立 HTML 同步配色和直角。

动效限于操作反馈：导航指示线与图表更新 240ms，按钮 160ms，无环境循环。个人设置提供本机动效开关，键盘和系统减少动态效果即时响应。窄屏减少图表标签密度，完整数据保留在交互和表格中。

本轮按用户要求只执行定向检查：类型检查、25 项现有图表/导出专项与主要页面视觉核对；不代表完整发布验收。界面改版已在分析恢复提交 `3c614f1` 之后独立本地归档，未推送或部署。以下保留历史设计与验证证据，以本节为当前方向。

## 历史实装：柠檬黄双主题

用户在设计预览中确认后，创建 `codex/lemon-frontend` 并落实到登录、概览、分析/提问、数据、报告、系统管理和个人设置。保留现有能力和真实统计口径，不引入新的界面依赖。

- 浅色：背景 `#e9ebe3`、面板 `#f8f9f4`、正文 `#252820`；深色：背景 `#1a1b19`、面板 `#252623`、正文 `#f0f2e9`。品牌与主要行动统一 `#e6f436`。
- 顶部横向导航与浅/深主题切换分别包在共同的圆角背景内。浅深模式保存在本机，首次跟随系统；主题初始化脚本在绘制前应用外观，图表和报告预览同步更新。
- 桌面面板 32px、手机 24px，按钮和切换组为胶囊，工具按钮为圆形。概览为标题 + 三项真实指标，主图与明细在左，AI 入口、推荐问题和数据概况在右。
- 成绩蓝、活动紫、完成率青绿；每个普通分析块采用对应色族。超过 6 个分组的活动构成图、双指标气泡图可以多色。图表图例、选择和详情使用同一组令牌，并将 CSS Color 4 色值转换为 ECharts 能识别的颜色。
- 下拉保留原生 select 语义与键盘操作，支持 `appearance: base-select` 的浏览器使用圆角浮层、勾选和指标色选中态，其他浏览器使用原生回退。比较维度箭头固定在框内右侧。
- 可点击摘要卡上浮 3px；展示面板上浮 2px，阴影伪元素透明度 0.6。采用 300ms `cubic-bezier(.23,1,.32,1)`，阴影/发光以 opacity 过渡，避免持续循环。按钮柔光跟随品牌或所在指标；键盘和减少动态效果保留即时反馈。
- 推荐问题无静态阴影，文本可安全换行，“试着问问”的消息图标紧随标题。数据概况和主图入口使用一致的圆形箭头，AI 星形图标不再套圈。
- 报告预览跟随工作台外观；独立下载 HTML 使用浅色，打印强制浅色纸面，保留数值、样本、口径与 SQL。

本轮验证：`pnpm typecheck`、25 条现有图表/导出专项测试、`git diff --check` 通过；隔离源码副本执行 Next.js webpack 生产构建通过。Edge 核对桌面两套主题、指标与维度切换、复杂图表、下拉浮层、数据/管理/账号页面、推荐问题与报告预览；320px/390px 的 `scrollWidth` 等于 `innerWidth`，抽屉 Escape 后焦点回到菜单按钮。HTML 实际下载并核对 72.11 分、新配色和隐私说明。没有重跑完整测试或认证 HTTP 套件，没有真实收费 AI 调用、真机或实际 PDF 保存验收。

实装截图位于当前会话 visualizations 目录的 `lemon-light-implemented.png` 和 `lemon-dark-implemented.png`。主开发页为 `http://localhost:3000/`；浏览器验收使用隔离副本及临时账号。以下保留前版设计与验证记录，旧配色和侧栏约定已由上述当前设计替换。

## 统计图表扩展（2026-10-16）

- 在学习全景和详细结果共用 `ChartViewPicker`，沿用炭灰底、浅植物绿选中态、8px 控件圆角；七种详细展示方式自动换行，手机三列排列、44px 点击区域。学习全景保留独立分组明细表，主图提供六种图形。
- 环形图与矩形树图用于活动构成，分母明确为当前可见活动总量；均分与完成率不作为占比。零活动分组保留在图例，全部为零时回退柱状图。
- 雷达图每轴代表一个课程/学期分组，比较同一指标，不构造综合能力分；3–12 组可用，成绩/完成率统一 0–100。活动量各轴共享同一最大刻度。
- 概览气泡图关联两项已返回指标，按课程名称匹配，横纵坐标写明指标，面积表示人数；配对不完整时使用人数横轴。详细页保持单项分析，以人数和当前指标形成气泡图。
- 新增十个低饱和植物色系图表令牌；同名分组颜色在筛选和排序后保持稳定。图例既解释颜色也支持选择分组，图形、方向键和详情面板同步更新；Canvas 保留无障碍摘要与表格入口。统计图形不加入入场动画。
- 本轮类型检查、7 条新增图表语义测试和差异检查通过。Edge 实测桌面、390px、320px，验证反复切图、搜索回退、空状态、排序、可见占比分母、树图点击、键盘和详情联动；手机页面无横向溢出。未重跑生产构建/全量测试，未作手机真机验证。
- 临时账号和运行配置隔离，使用当前扩充的模拟数据，未调用收费 AI、修改真实账号/配置或发布线上。截图：当前会话 visualizations 目录中的 `charts-treemap-desktop.jpg` 与 `charts-radar-mobile.jpg`。

## 信息与功能

- 默认进入“学习全景”：最高课程均分、可见课程活动总量、最高课程完成率；每张摘要都标明实际口径。微型图使用真实返回分组，不制造趋势或增长率。
- 主区包含可切换指标的课程图表、分组明细和报告入口；侧区提供一句话分析、可直接执行的推荐问题和数据档案。
- 概览三个指标并行读取，切换概览指标不重新请求。数据源改变时清空旧概览并取消旧请求；单项失败保留其余结果并提示。
- 侧栏保留学习全景、指标分析、数据、一句话分析、会话报告、系统管理与个人设置。
- 详细分析保留指标、课程/学期维度、柱状/折线/表格、刷新、搜索排序、分组选择、统计依据、SQL 与全部导出。图表与分组详情左右排列，窄屏上下排列。
- 搜索与排序直接可见；报告预览直接可达。导出 CSV/HTML 与打印入口沿用已有实现；账号权限、隐私阈值和 AI 服务配置不变。

## 视觉约定

- 主背景 `#181a18`，面板 `#222421`，主文字 `#f1f0eb`，次文字 `#a0a19b`，强调 `#d5e7aa`，边界 `#ffffff13`。
- 桌面侧栏 224px，内容边距 36px，主辅栏间距 24px，辅助栏 292px；面板 14–16px 圆角，控件 7–10px。
- 中文字体 PingFang SC / Microsoft YaHei，拉丁与数字优先 Avenir Next。标题 32px、面板标题 17px、摘要数字最高 42px，数值使用等宽数字。
- 仅对选中控件和交互反馈使用既有短过渡；统计数字与图表静态呈现，遵循减少动态效果设置。
- 手机摘要改为紧凑两列行式排版，使首屏能够看到主图；320px / 390px 页面不横向溢出，表格在自己的区域内滚动。900px 以下高度隐藏侧栏品牌说明，保证设置与账号入口可见。
