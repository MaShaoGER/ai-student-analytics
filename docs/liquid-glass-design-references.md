# 液态玻璃前端设计参考

整理日期：2026-10-21。

本文汇总液态玻璃的视觉参考、技能与学析台的探索方向。以下应用建议用于设计试验，尚未作为正式界面改版方案确认；本文不代表已接入任何组件库。

## 设计观察要点

- **材质与折射**：观察背景穿过边缘时如何弯曲，以及模糊、透明度和高光如何共同表达厚度。
- **内容可读性**：在复杂背景、滚动内容和深浅主题中，文字、焦点和选中状态都应清楚。
- **交互反馈**：按下及时响应；拖动跟随指针；动画能被后续操作打断；避免让文字持续扭曲。
- **视觉层级**：浮层与底层内容之间有明确距离；控制高光、阴影和玻璃层叠数量。
- **性能与降级**：正式接入时在目标浏览器和设备上验证；提供不支持折射时的简化材质，并尊重减少动态效果偏好。

## 学析台的建议探索范围

保留现有工业风格和信息结构，先做局部材质试验：

| 区域 | 探索方向 |
| --- | --- |
| 导航与工具条 | 轻度半透明、清晰选中态、克制的边缘高光 |
| AI 悬浮输入框 | 以通透外壳表达浮层，确保输入文字与按钮对比度稳定 |
| 标签与图表切换控件 | 试验玻璃选中块、短促按压反馈和连续位置过渡 |
| 弹窗、提示和小型浮层 | 按需要使用玻璃材质，检验遮挡和层级关系 |
| 图表、表格、长回答 | 优先使用清晰稳定的内容底色，避免材质干扰数据阅读 |

建议先制作两到三个独立预览方案：轻磨砂、边缘折射、局部高光。比较真实数据密度下的可读性和操作感，再决定采用范围。
