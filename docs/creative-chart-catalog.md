# 学析台 · 创意图表候选与实装备忘

记录日期：2026-10-23。状态：调研与候选设计，尚未实装。

用户确认继续沿用项目生成的虚拟校园数据，希望多收集一些小众、有作品集观感、可以交互探索的图表。本文件收录 **40 个候选方向**，包含独立图形、组合视图，以及同一统计图的布局和交互变体；数量不等于 40 种互不相关的统计方法，也不代表全部已经进入开发排期。

各条目的“项目映射、难度、批次、交互”是针对学析台的设计建议，不是参考网站提供的产品能力。参考优先使用作者作品、官方示例、原始项目仓库。链接访问与本地实现情况以记录日期为准；引入依赖前仍需验证版本兼容性。

## 1. 已确认方向与当前基线

- 数据继续使用 `data/sample/` 的虚构数据，不要求采集真实学生数据，也不需要引入其他学校的公开数据才能制作这些候选图表。
- 视觉优先考虑山脊、轨道、线束、细胞分区、花瓣字形、河流、地形色带等形态；具体指标、轴和数量仍来自确定性统计。
- 当前烟银玻璃界面以 [.interface-design/system.md](../.interface-design/system.md) 为准。玻璃用于容器，坐标、文字和统计标记保持锐利；不能用背景折射扭曲读数。
- 上一轮会话做过山脊图、径向热力图、河流图、学科关系星群的概念预览。它们不是正式图表入口，也没有因此扩展 AI 工具或报告导出能力。
- 现有柱状、折线、环形、矩形树图、雷达、气泡、箱线、桑基、热力、散点密度、哑铃、弦图和学科全景继续保留；下文明确标注复用和变体，避免重复建设。

## 2. 可直接利用的数据与统计快照

当前生成规模：1,200 名学生、18 门课程、4 个学期；每名学生每学期选 3 门课，每次选课有 16 周活动和 8 次作业。八张表的定义见[数据字典](data-dictionary.md)和[生成说明](../data/sample/README.md)。

| 快照代号 | 建议聚合内容 | 来源与连接粒度 |
| --- | --- | --- |
| D1 成绩分布 | 课程/班级/专业的样本量、均分、分位数、分档频数、及格率 | `student_outcomes`，学生—课程—学期；分组前按该粒度去重 |
| D2 学习节奏 | 课程/班级逐周活动总量、人均活动量、有记录人数 | `learning_activity`，学生—课程—学期—周 |
| D3 学科关系 | 两科共同选课有效样本、共同未达标人数及占比 | 同一学期内关联两份 D1 底层有效成绩；个体连接只在服务端进行 |
| D4 群体多指标 | 班级/专业/课程的成绩、出勤、作业完成和按时提交等指标 | `students` 关联课程事实，或利用 `student_term_summary`；同一个点/字形采用明确的群体与周期 |
| D5 互斥构成 | 按时/迟交/未交的计数与比例，或到课状态计数 | `assignment_submissions`、`attendance_weekly`；先合并计数再计算比例 |
| D6 层级数量 | 专业→班级→课程的访问量、应交作业数等可加总量 | 学生维表关联事实表后按层级聚合；使用人数时必须明确去重范围 |
| D7 连续学期路径 | 同一批学生各学期平均成绩所属档位的完整路径频数 | `student_term_summary`，学生—学期；完整路径聚合后才输出 |
| D8 作业过程 | 课程每次作业的得分分位数、有效提交人数和状态构成 | `assignment_submissions`，学生—课程—学期—作业；按作业序号/截止时间对齐 |
| M1 课程分类 | 课程→通识/数理/专业等固定展示层级 | 需要新增可审查的分类配置，或由虚拟数据生成器输出课程元数据；不是现有表字段 |

“数据已有”指能从上述虚拟表计算，不表示现有接口已经返回所需快照。D4 的多维查询、D7 的纵向连接、D8 的分位带等仍需要明确实现。

### 统一口径

1. 展示群体聚合，学生标识仅在服务端连接、去重和计数。可见分组、路径、交集和关系使用项目最少 3 名学生的规则；交互切片仍须重新满足阈值，不能靠相减推回被抑制的小组。
2. 出勤率按实际到课课时/应到课时计算；迟到和早退计入到课，请假缺席与旷课分开。作业完成率、按时提交率、课程完成率、及格率分开命名。
3. 未交作业没有成绩；没有记录不等于零。每周最终课程成绩不能由期末成绩重复填充出来。作业分位带只在确实存在的作业阶段显示。
4. 跨课程统计可能是选课人次，跨学期统计可能是人次；不能把交叠课程的去重人数直接加成总人数。层级面积优先使用可加总的活动次数。
5. 形态平滑、密度估计、视觉布局、归一化和动画插值需要有明确说明；它们不会产生新的实际观测或因果结论。
6. 当前模拟数据的学院、入学年份和学籍状态覆盖有限，不能仅凭存在字段就承诺有丰富的学院、年级和退学对比。

## 4. 形态与层级：C01–C10

### C01 山脊图 · Ridgeline

- **视觉与问题**：多层连续山峰，用于比较课程成绩集中在哪些分数段、是否出现双峰和长尾。
- **数据**：D1；服务端输出固定分数网格的密度或分档频数、样本量与分位数，不输出学生分数列表。
- **交互与实现**：课程排序、学期切换、及格线、选中一条山脊展开；D3 曲线或 ECharts 自定义系列。各课程使用一致的横轴和密度尺度。
- **边界**：五数概要不足以还原密度；平滑不能虚构越界成绩，也不能把被抑制区间补成零后画出完整山峰。
- **参考**：[D3 山脊图][r-ridgeline]。会话概念预览已有，正式模块待做。

### C02 径向热力图 · Radial Heatmap

- **视觉与问题**：像唱片和年轮；每圈课程、每个扇区周次，观察学期节奏。
- **数据**：D2；建议先用固定学期的课程×16 周人均活动量，颜色表示数值，半径只承担课程布局。
- **交互与实现**：旋转或选择周次、聚焦课程、与矩形热力图互切；D3 弧段绘制。圆周留出起止缺口，跨学期比较固定色域。
- **边界**：圆形是布局，不说明学习天然循环；不同半径格子的面积差不能用于比较活动总量。
- **参考**：[D3 弧段构造][r-arcs]（几何基础）。会话概念预览已有，正式模块待做。

### C03 河流图 · Streamgraph

- **视觉与问题**：课程活动形成柔和流带，展示活动量在各周如何变化。
- **数据**：D2；带宽用课程每周活动总量，或明确使用可加总的其他数量。若换成人均量，应另标口径，不把总带宽叫总访问量。
- **交互与实现**：图例隐藏、课程聚焦、周次游标和播放控制；D3 堆叠面积或现有 ECharts 能力扩展。
- **边界**：中心基线位置没有正负含义；排序变化需显式触发；均分、及格率等不能当作可加总的构成。
- **参考**：[Streamgraph transitions][r-stream]。会话概念预览已有，正式模块待做。

### C04 地平线图 · Horizon Chart

- **视觉与问题**：将波形分段折叠成深浅色带，适合在有限高度展示 18 门课的节奏。
- **数据**：D2；建议显示各课程每周人均活动相对该课程学期均值的差，正负和分层阈值固定。
- **交互与实现**：展开还原普通面积图，悬停显示原始值、基准和差值；D3 多层裁剪。切换学期时说明基准是否随学期变化。
- **边界**：正负差异和绝对活动量分开；折叠后的高度不能直接当原始数值，必须保留分层图例。
- **参考**：[D3 Horizon][r-horizon]。

### C05 螺旋热力图 · Spiral Heatmap

- **视觉与问题**：把多个学期的周活动排成连续螺旋，适合大图探索重复的学期位置。
- **数据**：D2；一圈可定义为一个学期的 16 周，明确标注学期之间的真实时间间隔没有按螺旋长度表达。
- **交互与实现**：沿轨迹选择一周、展开为直线时间轴；定制 SVG 几何，旧 D3 插件只作参考。
- **边界**：四学期仅 64 个周位置，不为填满螺旋制造每日观测；不能据图形外观推断季节周期。
- **参考**：[原作者 d3-spiral-heatmap][r-spiral]；该参考注明 D3 v4，不能默认兼容当前实现方案。

### C06 波形叠层 · Joy Division Style

- **视觉与问题**：大量细波形按层排列，适合制作课程学习节奏的封面式视图。
- **数据**：D2；横轴是周次，纵向分层是课程，波高为人均活动；不是 C01 的成绩分布。
- **交互与实现**：聚焦单层、排序、展开数值轴；复用线/面积几何与裁剪，课程顺序稳定。
- **边界**：属于波形布局变体；横向仅有 16 个观测，不额外添加“细波纹”冒充记录。
- **参考**：[D3 PSR B1919+21][r-wave]（视觉层叠参考）。

### C07 可缩放圆形打包 · Zoomable Circle Packing

- **视觉与问题**：像一组可钻入的细胞或星团，探索专业→班级→课程的层级。
- **数据**：D6；圆面积优先表示访问量或作业应交数，颜色可表示同一节点的有效成绩均值。
- **交互与实现**：点击放大、面包屑返回、同步展开数值表；D3 hierarchy/pack。父节点显示实际总量。
- **边界**：圆之间的空隙属于布局；不能用课程人数相加代替不重复学生总数，也不能把均分当面积构成。
- **参考**：[D3 Zoomable circle packing][r-pack]。

### C08 Voronoi 树图 · Voronoi Treemap

- **视觉与问题**：不规则细胞切分成一幅“数据矿石”，层级面积比矩形树图更有作品集感。
- **数据**：D6；建议沿用 C07 的同一快照，让两种形态可切换。
- **交互与实现**：选择细胞、逐层展开、学期切换时稳定布局；需要迭代布局、随机种子、面积误差与耗时上限，必要时后台线程计算。
- **边界**：不是地理地图；面积误差必须受控，不能为了形状漂亮随意改权重。旧插件公开说明支持 D3 v4/v5/v6，现代 D3 兼容性待验证。
- **参考**：[原作者 d3-voronoi-treemap][r-voronoi]。

### C09 可缩放旭日图 · Zoomable Sunburst

- **视觉与问题**：同心扇环逐层展开，展示专业、班级和课程的活动量构成。
- **数据**：D6；叶节点使用一致的可加总计数，缺失层级单独标记。
- **交互与实现**：点击扇区钻取、中心返回、路径面包屑；D3 partition 或 ECharts sunburst 的适配评估。
- **边界**：面积/角度用于数量，成绩均分只适合另作颜色或提示值；是现有树图能力的层级扩展。
- **参考**：[D3 Zoomable sunburst][r-sunburst]。

### C10 可缩放冰柱图 · Zoomable Icicle

- **视觉与问题**：层级像横向地层展开，相比圆形更容易容纳中文标签。
- **数据**：D6，与 C07–C09 共用快照。
- **交互与实现**：点击放大层级、返回上级、聚焦专业；D3 partition。可作为圆形层级图的窄屏替代。
- **边界**：宽度表示数量，层级深度不是时间或学习进步。
- **参考**：[D3 Zoomable icicle][r-icicle]。

## 5. 关系与集合：C11–C20

### C11 径向边捆绑 · Hierarchical Edge Bundling

- **视觉与问题**：细线沿层级骨架汇成束，突出哪些学科之间存在共同薄弱。
- **数据**：D3+M1；课程是叶节点，固定课程分类形成层级，边的含义沿用共同未达标人数或占比。
- **交互与实现**：悬停/点击课程显示关联，调节关系阈值，保持节点次序；D3 cluster、层级路径和 bundle 曲线。
- **边界**：M1 尚需配置；没有有意义层级时先用 C12/C13。线的弯曲、靠近和捆绑不代表课程先修或因果。
- **参考**：[D3 Hierarchical edge bundling][r-bundle]。已有弦图可复用关系统计，但渲染不是已完成能力。

### C12 学科星群 · Force-directed Network

- **视觉与问题**：课程节点与细连接形成可探索的星群，适合聚焦某科的关联范围。
- **数据**：D3；节点面积可表示未达标人数，边宽表示共同未达标人数，提示同时给共同有效选课样本。
- **交互与实现**：节点选择、拖动、关系阈值、冻结布局；D3 force，固定种子，孤立节点单独容纳，静止后停止模拟。
- **边界**：节点距离是布局结果，不是精确相关系数；孤立不等于学科独立或没有问题。
- **参考**：[D3 Disjoint force-directed graph][r-force]。会话概念预览已有，正式模块待做。

### C13 弧线关系图 · Arc Diagram

- **视觉与问题**：节点在一条线上排列，连接弧线像乐谱和线束，适合对照课程标签。
- **数据**：D3；排序可按课程类别、均分或连接数，但必须给出当前排序含义。
- **交互与实现**：切换排序、聚焦一科、过滤弱边；D3 路径绘制，保留连线对应数据表。
- **边界**：长弧只表示节点在当前排序下相距远，不表示更强关系。
- **参考**：[D3 Arc diagram][r-arc-diagram]。

### C14 抛物线弧图 · Parabolic Arcs

- **视觉与问题**：多条弧线形成有节奏的拱形束，适合全屏展示稀疏学科关系。
- **数据**：D3；与 C13 共用结果，属于关系布局变体。
- **交互与实现**：在直线、圆弧、抛物线布局间切换；D3 自定义曲线，标签仍按固定规则排列。
- **边界**：曲率不新增统计意义，不能靠夸大弧高暗示强弱；如需编码边权，应独立用线宽并提供图例。
- **参考**：[D3 Parabolic arcs][r-parabolic]。

### C15 蜂巢轴图 · Hive Plot

- **视觉与问题**：课程沿多条径向轴排列，弧线跨轴连接，比自由力导向图更有几何秩序。
- **数据**：D3+M1；轴表示课程类别，轴上的位置可表示均分或未达标率，边表示共同薄弱。
- **交互与实现**：选择轴、切换明确的轴内排序、突出跨类关系；定制 SVG 布局。
- **边界**：先定轴分类和位置编码。不能仅为形成三角形，把学科随意分成三组并暗示有业务意义。
- **参考**：[Mike Bostock 的 Hive Plots][r-hive]。

### C16 多圈关联图 · Circos Style

- **视觉与问题**：外圈成绩分布、中圈周活动热力、内圈学科关联，形成一张可探索的学科总图。
- **数据**：D1+D2+D3；三个环层使用相同课程顺序、学期和筛选范围。
- **交互与实现**：选择课程联动所有环、逐层开关、局部放大；复用现有弦图的统计与色彩规则，外圈几何另做。
- **边界**：这是组合视图，不是新综合评分。不同环分别有单位；不可让环宽、发光或半径同时暗示无依据的“重要性”。
- **参考**：[Visual Cinnamon 作品集][r-artist]（复合径向视觉参考）、[D3 边捆绑][r-bundle]（关系布局基础）。

### C17 排序邻接矩阵 · Reordered Adjacency Matrix

- **视觉与问题**：方阵通过排序显出关系块，适合从艺术性关系图返回可比较的结构。
- **数据**：D3；颜色表示共同薄弱占比，提示显示分子和共同有效样本分母。
- **交互与实现**：名称/类别/关系聚类排序、行列聚焦、切换关系图；复用热力图，增加稳定排序和必要的聚类计算。
- **边界**：如果使用自动聚类，应标算法和距离定义；块状形态不等于已发现新的真实学科分类。
- **参考**：[Mike Bostock 的 Matrix Diagram][r-matrix]。

### C18 集合交集图 · UpSet

- **视觉与问题**：连接点阵配合交集柱，查看“哪些学科同时未及格”比多集合维恩图更清楚。
- **数据**：D1；服务端按同一学期的未及格集合计算交集。首版只允许选择少量课程，区分精确交集与包含式交集。
- **交互与实现**：选择课程集合、按交集人数排序、点击交集查看聚合摘要；定制点阵与柱形，UpSet.js 仅列为参考候选。
- **边界**：“不在该未及格集合”不等于通过，可能未选课或缺分；抑制小交集，不把重叠交集相加成总人数。
- **参考**：[UpSet.js 官方介绍][r-upset]。

### C19 平行集合 · Parallel Sets

- **视觉与问题**：多列分类由带子连接，适合探索出勤档位、作业状态和成绩档位之间的数量构成。
- **数据**：D5+D1；同一个学生—课程—学期先归为互斥类别，再按完整路径计数。
- **交互与实现**：重排分类轴、选中某一路径、查看原始分子分母；复用现有桑基统计基础，增加可解释的类别轴布局。
- **边界**：同一周期的分类关联不是时间先后，也不是“出勤导致成绩”的证据。
- **参考**：[D3 Parallel sets][r-parallel-sets]。

### C20 多学期冲积图 · Longitudinal Alluvial

- **视觉与问题**：四个学期的成绩档位由带子串起，形成可以讲述群体变化的河道。
- **数据**：D7；沿学生编号连接同一批人，只返回完整路径频数与必要的抑制说明。缺失期单列或明确使用完整记录群体。
- **交互与实现**：选择前后期、聚焦起点或完整路径、显示群体规模；桑基布局扩展，按真实路径而非仅逐期边总量支持追踪。
- **边界**：现有同学期出勤→作业→成绩桑基不是本图。学期选课会变化，学期平均成绩提升不能单独证明同科能力提升；被抑制路径不能通过相邻边重建。
- **参考**：[D3 Parallel sets][r-parallel-sets]（分类流带基础）。

## 6. 多指标与分布：C21–C30

### C21 三元图 · Ternary Plot

- **视觉与问题**：群体在三角形中形成分布，直观看出作业更偏按时、迟交还是未交。
- **数据**：D5；每个点为课程/班级聚合，三项比例来自互斥状态且总和为 100%。
- **交互与实现**：选择角落区域、固定课程对比、显示三项实际比例与样本；D3 重心坐标。Plotly 示例是编码参考，不代表需要安装 Plotly。
- **边界**：成绩、出勤率和活跃量不构成总和为 100% 的三个部分，不能直接塞入三角形。
- **参考**：[Plotly 官方 Ternary plots][r-ternary]。

### C22 可刷选平行坐标 · Brushable Parallel Coordinates

- **视觉与问题**：每个群体是一条跨指标的线，可直接框选“成绩高、作业按时率低”等组合。
- **数据**：D4；首版点/线代表班级×课程等合格聚合单元，建议最多 4–6 个有明确单位的指标。
- **交互与实现**：轴区间刷选、轴重排、联动表格；D3 brush 或评估已有 ECharts parallel 能力。
- **边界**：各轴可有不同单位，不能把连线形状叫综合能力。刷选后只联动已批准的群体快照，不直接返回学生名单。
- **参考**：[D3 Brushable parallel coordinates][r-parcoords]。

### C23 径向投影 · RadViz

- **视觉与问题**：多个指标作为圆周锚点，群体分布在圆内，像有方向性的星盘。
- **数据**：D4；固定指标归一化范围后计算投影，显示原始数值和归一化方式。
- **交互与实现**：选择群体、比较锚点、在限定配置中重排锚点；投影计算与 SVG 分开实现。
- **边界**：点的位置依赖尺度和锚点安排，不是地理位置、精确相似度或模型诊断。分母为零/全缺失时不生成坐标。
- **参考**：[pandas 官方 RadViz 说明][r-radviz]（方法参考，不引入 Python 作为前端依赖）。

### C24 联动散点矩阵 · SPLOM

- **视觉与问题**：多组指标两两组成小图，在一格框选、所有格同步突出。
- **数据**：D4；每个点是同一粒度的班级/课程聚合。首版使用同一套完整有效群体，避免各格样本暗中变化。
- **交互与实现**：刷选联动、切换指标、对角线显示分布；D3 共享选择状态。
- **边界**：群体均值之间的关系不等于学生个体关系；最多先做 4 个指标，窄屏选择一对指标放大。
- **参考**：[D3 Brushable scatterplot matrix][r-splom]。

### C25 密度等高线 · Density Contours

- **视觉与问题**：把密集关系画成地形等高线，展示高密度区域与稀疏区域。
- **数据**：D4 或服务端二维分档频数；例如出勤率×成绩。由频数估计的密度应标为估计，并保留分箱参数。
- **交互与实现**：切换等高线/分档热力/散点密度、点选区域查看频数；服务端或受控转换生成等值轮廓。
- **边界**：不把等高线当置信区间或风险边界，不跨小样本隐藏区域补出连续山脉。
- **参考**：[D3 Density contours][r-contours]。

### C26 六边形分箱 · Hexbin

- **视觉与问题**：关系空间变成蜂窝密度，适合替代重叠散点。
- **数据**：D4 底层统计；服务端按固定二维尺度确定分箱，返回频数及范围，低样本箱合并或隐藏。
- **交互与实现**：点选蜂窝、切换指标和粒度；SVG 六边形或 Canvas，颜色表示频数。
- **边界**：不能把已公开的矩形频数随意拆成六边形并称精确统计；改变显示大小时保持统计网格或明确重新计算。
- **参考**：[Observable Plot Hexbin][r-hexbin]。

### C27 聚合蜂群图 · Aggregated Beeswarm

- **视觉与问题**：点沿数值轴紧密排布，展示不同班级/课程聚合单元的分布与差异。
- **数据**：D4；每点一个满足样本阈值的聚合单元，位置表示该组均分，点面积可表示组内人数。
- **交互与实现**：按课程分面、选择聚合点、回看对应统计；采用确定性的避碰布局。
- **边界**：本图展示群体均分的分布，不是学生成绩分布；不把匿名学生明细发到浏览器，也不随机抖动出虚构成绩。
- **参考**：[Observable Plot Dodge/Beeswarm][r-beeswarm]。

### C28 小提琴图 · Violin Plot

- **视觉与问题**：对称分布像叶片或乐器，比较课程成绩集中度和偏态。
- **数据**：D1；服务端输出密度采样、分位数、有效样本，统一估计参数与边界处理。
- **交互与实现**：课程比较、半边/镜像切换、中位数与四分位线；与 C01 共用密度快照。
- **边界**：只靠箱线图五数概要无法生成真实小提琴轮廓；小样本或常数分数要有明确退化形式。
- **参考**：[Vega 官方 Violin Plot][r-violin]。

### C29 聚合雨云图 · Aggregated Raincloud Variant

- **视觉与问题**：半小提琴、箱线和下方“雨点”组合，一张图同时保留分布形态和原始计数感。
- **数据**：D1；上方密度与箱线来自同一统计群体，下方使用分数分档气泡/刻线，大小表示频数。
- **交互与实现**：切换课程、选择分数区间、关联数值表；组合 C28 和现有箱线图，标注雨点单位。
- **边界**：这是保留聚合边界的雨云变体。下方一个点不是一个学生，不绘制随机点来伪装个体原始分布。
- **参考**：[RainCloudPlots 原项目][r-raincloud]。

### C30 双变量热力图 · Bivariate Heatmap

- **视觉与问题**：课程×学期矩阵中，一个格子的颜色同时表达两个指标，形成更细腻的色彩结构。
- **数据**：D4；例如出勤率与作业按时率各分成三档，组成 3×3 图例；每格同时保留两个实际数值。
- **交互与实现**：点击双变量图例筛选、切回单指标、显示原值；复用热力渲染，增加双变量配色与图例。
- **边界**：先验证颜色可区分且明暗可读。参考地图仅用于借鉴双变量编码，不虚构校园坐标或地域含义。
- **参考**：[Joshua Stevens 的双变量配色方法][r-bivariate]。

## 7. 变化、字形与叙事：C31–C40

### C31 排名变化图 · Bump Chart

- **视觉与问题**：课程线在四个学期之间穿插，突出排名的相对变化。
- **数据**：D1；按每期课程均分或及格率计算排名，预先规定并列排名规则，同时保留实际值和样本量。
- **交互与实现**：选中课程、固定比较组、切换排名指标；可复用折线渲染与标签避让。
- **边界**：目前只有四个学期，不制造中间排名；排名进步不等于绝对成绩提高，也不是同一批学生的个人进步。
- **参考**：[RAWGraphs 官方更新中的 Bump Chart][r-rawgraphs]、[D3 线形基础][r-lines]。

### C32 排名缎带图 · Rank Ribbon

- **视觉与问题**：将 C31 的线变成有宽度的缎带，突出交叉与次序更替。
- **数据**：D1；首版使用固定带宽表达排名位置；若带宽另表样本量，必须单独图例并限制遮挡。
- **交互与实现**：课程聚焦、按学期逐步播放、切回细线排名；自定义带状路径与稳定数据键。
- **边界**：属于排名图的视觉变体。带子跨越与动画帧不表示学生在课程间流动。
- **参考**：[RAWGraphs Bump Chart 记录][r-rawgraphs]、[D3 面积路径][r-areas]（实现基础）。

### C33 连接散点轨迹 · Connected Scatterplot

- **视觉与问题**：一条在二维平面行进的轨迹，展示两个学习指标如何随周次共同变化。
- **数据**：D2 与出勤周表；固定课程、学期和有效群体，横轴人均活动量，纵轴出勤率，点按实际周次连接。
- **交互与实现**：时间游标、逐周定位、课程小多图；D3 路径、方向提示和周次标签。
- **边界**：不要把期末成绩当每周成绩；同时变化不证明因果。缺失周断开，插值只表示视觉过渡。
- **参考**：[D3 Connected scatterplot][r-connected]。

### C34 分位带图 · Quantile Bands

- **视觉与问题**：中位数线被多层柔和带包围，展示作业成绩分布随阶段的变化。
- **数据**：D8；对每次作业的有效提交成绩计算中位数、25–75% 和可选 10–90% 分位，显示各次有效样本。
- **交互与实现**：聚焦一次作业、开关分位带、联动未交比例；D3 area 或现有面积系列扩展。
- **边界**：分位带不是均值置信区间，也不是未来预测；作业之间样本可能不同，未交不补零。
- **参考**：[Observable Plot Area][r-area-mark]（区间几何基础）；分位口径由本项目定义。

### C35 斜率图 · Slopegraph

- **视觉与问题**：左右两列读数由细线连接，适合做两学期对照的编辑式排版。
- **数据**：D1，与已有哑铃图的两期比较结果共用。
- **交互与实现**：选课程、显示差值、切换左右周期；现有折线/自定义 SVG，重点是中文标签避让。
- **边界**：这是两期比较布局变体；不同选课群体的均分差不是同一批学生的进步。
- **参考**：[D3 线形基础][r-lines]。无需为外形变化建立另一套统计口径。

### C36 马赛克图 · Marimekko/Mosaic

- **视觉与问题**：列宽与列内分块共同表达两层构成，画面像按数量排版的拼贴。
- **数据**：例如固定学期的专业人数×学生学期平均成绩档位；每名学生在该快照只落入一个专业和一个档位。
- **交互与实现**：切换构成维度、选择一块看人数和比例；定制矩形布局。列宽表示组人数，列内高度表示档位比例。
- **边界**：面积为联合人数；课程选课人次方案要另标单位，不能与去重人数混用。
- **参考**：[RAWGraphs 官方图表项目][r-rawgraphs-charts]（构成图参考与后续源码定位入口）。

### C37 数据花园 · Flower Glyphs

- **视觉与问题**：班级/专业成为一朵花，固定花瓣分别表示选定课程均分，像可探索的数据植物标本。
- **数据**：D4；首版建议固定 4–6 门课、相同顺序和 0–100 分刻度，花心显示群体样本。缺课或样本不足的花瓣留缺口。
- **交互与实现**：选花展开标准图、在两个学期间对照、固定专业；定制径向字形和避碰布局。
- **边界**：花瓣长度有定义，旋转、花型和开合不能暗示未定义的能力或性格；不同花必须共用同一套编码。
- **参考**：[Shirley Wu 的作品介绍与 Film Flowers][r-shirley]（字形设计参考，不复制作品图像或代码）。

### C38 单元点阵与重排 · Unit/Waffle Morph

- **视觉与问题**：同一批计数单元在整体、分类和时间对照间重排，适合讲述作业提交构成。
- **数据**：D5；例如每个小格代表 100 次作业机会，尾数单独标注，或用明确的比例单元。不使用学生头像。
- **交互与实现**：总体↔课程↔提交状态重排、播放/暂停、选中类别；SVG/Canvas 稳定键与确定性单元分配。
- **边界**：格子不是实际学生，四舍五入和余数要说明；只有守恒的同一统计总体适合重排，不能借形变暗示无依据的跨期个体追踪。
- **参考**：[Observable Plot Waffle][r-waffle]。

### C39 时间透镜 · Focus + Context

- **视觉与问题**：下方完整时间带保留全局，上方放大所选区间，让短期变化与全学期背景同时存在。
- **数据**：D2，可给 C03/C04/C06 等时间图共用。
- **交互与实现**：刷选周区间、移动透镜、键盘选择范围；D3 brush/zoom 或现有图表 dataZoom 的适配。
- **边界**：这是交互能力，不是新统计图。只放大现有 16 周，不通过重采样补出每日行为；选中群体改变时继续执行样本规则。
- **参考**：[D3 Zoomable area chart][r-time-lens]。

### C40 三维分离山脊 · 3D Ridgeline

- **视觉与问题**：将 C01 的成绩山脊按课程分层摆到空间中，适合有限的旋转和透视展示。
- **数据**：D1；横轴成绩，波高为密度，纵深只是课程顺序，各山脊之间保持分离。
- **交互与实现**：受限旋转、点选课程、立即切回二维；独立评估 WebGL 渲染与既有背景的性能竞争，不能假定新三维依赖兼容 ECharts 6。
- **边界**：分类课程不是连续空间，不在课程之间补出连续“地形曲面”。不得依赖透视读精确数值；低性能、减少动态、打印统一降为 C01。
- **参考**：[D3 山脊图][r-ridgeline]（统计基础）、[Shirley Wu 作品介绍][r-shirley]（空间可视化方向）；本条是项目实验设计，没有现成组件接入结论。

## 8. 建议实装顺序

这是当前建议，用户尚未逐项确认；候选文档不等于要求一次开发全部图表。

| 批次 | 图表 | 目的 | 共用基础 |
| --- | --- | --- | --- |
| 首批：建立辨识度 | C01 山脊、C02 径向热力、C03 河流、C07 圆打包 | 先形成四种明显不同的主图形态 | 成绩分布、周活动、层级数量快照 |
| 第二批：关系作品 | C11 边捆绑、C12 星群、C15 Hive、C16 多圈关联 | 同一份关系统计在不同构图下探索 | D3、M1、稳定课程色彩与选择状态 |
| 第三批：深入分析 | C18 UpSet、C21 三元、C22 平行坐标、C29 聚合雨云 | 保留视觉特点，同时增加有用的探索能力 | 群体指标、交集与分布快照 |
| 第四批：叙事和实验 | C04 地平线、C08 Voronoi、C20 跨期冲积、C31 排名、C33 轨迹、C37 花园、C38 点阵 | 再扩充展览感、联动和变换 | 明确单位、时间、群体与布局语义 |
| 后续备选 | 其余条目，尤其 C40 | 在实装与性能反馈后继续补齐 | 优先复用已有快照，按实际需要进入排期 |

首批不是把四张图挤进首页。建议提供一个图表探索入口，选中一张后给足画布，保留指标、范围、样本与“查看数值表”；常规工作台继续按问题选择合适图形。

## 9. 接入设计备忘

以下均为待实施方案，不是现有接口保证。

### 9.1 统计和外形分开

- 建立候选图表元数据：稳定编号、中文/英文名、可用快照类型、指标、维度、单位、数据上限、降级视图、是否支持导出。
- 一份 D1 可供山脊、小提琴、雨云和分离山脊复用；一份 D3 可供弦图、边捆绑、Hive、星群与矩阵复用，避免各图偷偷更改口径。
- 快照至少包含数据集版本、筛选范围、统计粒度、样本量、单位、抑制信息及估计/平滑参数。禁止模型生成坐标、人数、密度或原始学生行。
- 对话内换形态复用同一快照，不额外调用模型；新增问题/范围按受限统计重新执行。历史保存的是事实快照及版本，不是重开时随机重算的画面。

### 9.2 渲染器选择

- 普通图继续使用现有 ECharts；对能清楚适配的候选，优先评估已有系列或 `custom`，避免引入重复的整套图表框架。
- 径向、层级、密度、边捆绑等需要较大几何控制时，优先评估按需使用 D3 模块+SVG；D3 负责布局/几何，React 负责容器和状态，约定清晰的 DOM 所有权。
- Plotly、Vega、pandas、RAWGraphs 等在本文件中主要是方法与效果参考，不表示需要全部安装。
- 多数快照只有课程、班级或有限分档，先验证 SVG。Canvas/WebGL 在实际标记数量和性能测量证明需要时引入；大型布局设置时间和迭代上限。
- 不直接照搬旧版 D3 插件。Voronoi、螺旋等需单独验证模块格式、几何稳定性、取消、内存和当前依赖的兼容性。

### 9.3 作品集风格与可用性

- 延续烟银底色、细线、清楚留白，课程颜色复用 [course-colors.ts](../lib/analysis/course-colors.ts)。外形改变时保持同一课程颜色；颜色用于分类或数量，不能只为装饰随机变化。
- 一次突出一个主图，允许全屏探索。复杂图默认只显示必要标签，焦点、提示和可访问的选择器补充细节，不能只支持鼠标悬停。
- 动效优先表现选择、重排、缩放和真实快照切换。遵循当前动效偏好、系统减少动态和可打断原则；不自动无限旋转、不制造假实时数据流。
- 窄屏切换为单图、短标签、范围选择与数值表；复杂圆形图可以降级为矩阵或层级列表，不能把整张图等比缩到标签无法阅读。
- 图表内部不叠玻璃纹理、像素折射或影响色阶的强光。打印采用静态清晰图，不把 WebGL 画布是否可导出留到上线时才处理。

### 9.4 实装验收

- [ ] 为每个进入排期的候选确定具体问题、快照粒度和图例，不只确定一个名字。
- [ ] 服务端独立复算数值；检查多表连接不放大计数，空值和小样本处理正确。
- [ ] 检查各视图总量/分布/分位数来自同一快照；估计误差、归一化和插值有说明。
- [ ] 交互选择、取消、重排、缩放、键盘和触控可用；多图联动不泄露个人数据。
- [ ] 深浅主题、窄屏、长中文课程名、缺数据、单组和常数值等状态可读。
- [ ] 验证关闭动效、隐藏标签页、离屏和卸载时不残留动画、模拟或监听器。
- [ ] 数据表、AI 工具、历史、报告分别声明支持范围；只完成图库演示不标为全链路完成。
- [ ] 验证实际导出与打印；三维和复杂交互图提供二维/表格降级。
