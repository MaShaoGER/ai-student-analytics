# 演示现场运行手册（AI）

用途：省赛/评审现场 10–15 分钟演示。目标不是“AI 永远不出错”，而是**出任何一类故障时，不冷场、不临时改配置、评委能当场得到一句可核对的话**。

配套文档：[AI 接入（百炼）](bailian-qwen.md)｜[智谱试用与 429/1305](zhipu-glm.md)｜[备份、恢复与回滚](recovery.md)｜[AI 交接单](ai-handover.md)｜[AI 评测基线](ai-eval-cases.md)｜[工作台使用指南](workspace-guide.md)

## 0. 先记住三件事

1. **固定问题不依赖 AI，也不依赖网络**：10 条固定问题命中本地已验证计划（`lib/analysis/golden-cases.ts`），没有模型密钥也能出图出数。演示的“底座”永远是它们。
2. **AI 只选分析方式与措辞，数字由本地统计计算**：被问到“AI 在哪一步”时，照读：“模型只负责把问题翻译成受限的分析计划，再把结果解释成人话；数字、排序、样本数都是本地 DuckDB 算的，模型拿不到 SQL。”
3. **现场不修配置**：改密钥、改模型、改预算都放到 24 小时检查单里。现场只做“降级 + 取证 + 继续演示”。

## 1. 演示前 24 小时检查单

逐项打勾，任何一项不通过就当天修，不要留到现场。

- [ ] **AI 状态**：管理员登录 → 系统管理 → AI 配置，确认“允许 AI 分析”已开启、模型名正确（百炼 `qwen3.7-flash` 或智谱 `glm-4.7-flash`）、协议/基础地址正确、显示“已配置密钥”、输入/输出单价不为空。
- [ ] **测试连接**：点一次“测试连接”，必须返回**有效分析计划**（HTTP 200 不算通过），记录模型名、耗时、token 用量与时间。连接测试计入用量，不要反复点。
- [ ] **3 条自由问题预演**（真实模型，逐条记录实际结果与耗时）：
  1. `各科成绩分布如何？` → 期望成绩分布（热力图/表格）+ “数字从哪来”；
  2. `按学期看学习活跃次数的变化趋势。` → 期望折线图 + 学期维度；
  3. `缺勤次数和成绩有关系吗？` → 期望关系图（散点/密度）+ 口径说明。
  备用澄清演示：`分析学生表现。` → 期望要求澄清，不执行查询。
- [ ] **预算余量**：管理页查看总调用/近 1 小时/近 24 小时用量；确认四项预算（单次/小时/天/30 天）足够覆盖“预演 + 现场 10 次左右调用”，又不会把单次预算卡得比一次请求的估算还低。服务商控制台确认免费额度/扣费方式（百炼可开“免费额度用完即停”）。
- [ ] **数据源可用**：分别切换 `demo` 与 `oulad` 各问一条固定问题，确认都有结果；确认 `data/fixtures/golden` 或 `data/sample` 文件在位，没有误删/误移。
- [ ] **备份与回滚确认**：
  - `records/` 已有最近备份（`node scripts/recovery.mjs backup ...`，见 [recovery.md](recovery.md)），并手工备份 `records/system/`（仓库没有自动配置备份）；
  - `APP_SETTINGS_KEY` 在**仓库外**的私有位置有副本（丢了它，`ai-config.json` 里的密钥就解不开）；
  - 若已部署：确认本地保留上一版可用镜像，`node scripts/rollback-image.mjs` 预演通过；
  - 现场演示机不是唯一的记录副本。
- [ ] **现场账号与入口**：演示账号已登录、AI 对话入口固定（导航“智能分析”），深浅色主题各看一遍，投影分辨率下文字可读。
- [ ] **取证工具就绪**：系统截图快捷键可用；准备一个空白记录表（见第 5 节）。

## 2. 演示前 1 小时检查单

- [ ] 网络：有线优先，手机热点备用；确认 AI 服务商域名可访问（不需要登录，能建立 HTTPS 连接即可）。
- [ ] 再点一次“测试连接”，看到有效计划即可（1 次，够用就好）。
- [ ] 完整跑 **1 条**自由问题到结果卡出现，确认“分析方式 + 模型名 + 数字从哪来”都在；确认耗时在可接受范围（约 2–5 秒）。
- [ ] 打开管理页费用/预算页面，确认没有刚触发的告警。
- [ ] 刷新一次页面，确认登录态与数据源选择正常。
- [ ] 关闭无关标签页/通知；录屏可选，但截图必须开着。

## 3. 演示动线（照读版）

1. **先固定问题**（不赌网络）：`比较各课程平均成绩。` → 柱状图 + 每组样本数。
2. **再一条自由问题**：`各科成绩分布如何？` → 热力图/表格。
3. **读结果卡**：“这块是分析方式——由 AI 生成分析计划，模型是 `xxx`；下面的‘数字从哪来’是本次分组数与口径，数字由本地统计计算。”
4. **追问一次**：`改成表格。`（或点结果卡切换）→ 说明“追问只改展示，不重新问模型”。
5. **展示边界**：`分析学生表现。` → 系统要求澄清；照读“它不会硬猜，也不会去查个体名单。”
6. 收尾一句：“AI 出问题时，固定问题和本地分析照常可用——这是设计，不是兜底。”

## 4. 四套降级话术（+ 数据源不可用）

原则：**先判断是哪一类（看页面提示/错误码），再执行动作，最后用一句话把“不是系统算错”说清楚**。错误码与响应体以 `output/impl/ai-improvements-round2.md` 的冻结契约为准。

### A. 断网 / 网络不可达（页面提示网络失败、请求超时，或模型请求直接 fetch 失败）

- 动作：立刻停止自由提问；切到固定问题/数据浏览等本地能力；手机热点可快速恢复时再切回。
- 对评委/老师照读：
  > “现场网络到模型服务不通，AI 问答暂时不可用。系统里的固定分析和统计数据是本地的，不依赖外网，我继续用它们演示；网络恢复后自由提问马上可用。”
- 恢复后：先问一条固定问题确认本地链路，再问一条自由问题；不要连续重试。

### B. 429 / 1305 服务过载（错误码 `AI_PROVIDER_OVERLOADED` 或 `AI_PROVIDER_RATE_LIMITED`，HTTP 429，`Retry-After: 30`）

- 判断：智谱免费模型常见 `429 / 1305`（平台过载）；`1302` 是账号速率限制。不是密钥坏了，不要重新生成/替换密钥。
- 动作：**不要连点**；等约 30 秒；这期间用固定问题继续；仍失败就本轮不再试自由提问。
- 对评委/老师照读：
  > “模型服务商当前限流，系统已经识别为‘服务过载’而不是连接失败，不会自动重试扣费。我们先用已验证的固定分析继续，稍后这一步可以再演示。”
- 恢复后：先 `测试连接`（1 次）再恢复自由提问。

### C. 预算耗尽（错误码 `AI_BUDGET_EXCEEDED`，HTTP 429；页面提示“本月 AI 用量已达管理员设定的上限”）

- 判断：管理页用量接近/达到四项预算之一；本次提问**没有发给模型**，不产生新费用。
- 动作：现场**不要**临时改预算；改用固定问题。若必须现场恢复：仅允许管理员按 24h 检查单里预演过的改法，把小时/天预算临时上调一档，演示结束**立即改回**并记录。
- 对评委/老师照读：
  > “AI 调用有预算上限，这是成本保护；本次提问没有发出去，也没有产生费用。演示继续用本地固定分析，预算调整需要管理员操作，我们不在现场改配置。”
- 恢复后：确认用量页数字回落/预算已改回，再做一次自由提问。

### D. AI 未配置 / 密钥失效（错误码 `AI_NOT_CONFIGURED` 503；或 `AI_PRICING_REQUIRED` 503 表示单价未填；或密钥解密失败）

- 判断：
  - `AI_NOT_CONFIGURED`：AI 未开启/未填密钥/模型为空；
  - `AI_PRICING_REQUIRED`：单价没填，系统拒绝调用；
  - 测试连接报“密钥不可用/解密失败”：`APP_SETTINGS_KEY` 与 `ai-config.json` 不匹配（换过密钥或换了机器）。
- 动作：现场不用修；固定问题照常。会后按 [ai-handover.md](ai-handover.md) 由管理员处理：确认 `APP_SETTINGS_KEY` 未变 → 重新保存密钥 → 测试连接。**不要在评委面前粘贴密钥**。
- 对评委/老师照读：
  > “这台机器的 AI 配置没就绪（密钥或单价问题），系统按设计拒绝了调用，避免误扣费。固定分析不受影响，我先演示数据链路；配置恢复由管理员按交接单处理。”

### E. 数据源不可用（错误码 `DATA_SOURCE_UNAVAILABLE` 503，文案“当前数据源读取失败，请换一个数据源，或联系管理员检查数据文件。”）

- 判断：**不是 AI 故障**，是数据文件读不到。切换数据源（`demo` ↔ `oulad`）先试一次；仍失败则说明是数据文件缺失/权限问题。
- 动作：切到可用数据源；若都不可用，展示已导出的报告/CSV（报告中心）并说明数据文件问题。
- 对评委/老师照读：
  > “这是数据文件读取失败，不是模型问题。系统把它单独标成数据源不可用；换一个数据源或恢复数据文件即可，AI 配置不需要动。”

## 5. 现场取证（出错时 30 秒内做完）

1. **截图**：页面错误提示全文（含时间/地址栏）、结果卡或对话状态。**不要拍**管理页里的密钥输入框、`.env*`、终端里的环境变量。
2. **记时间**：发生时间精确到分钟与时区（如 `2026-11-18 15:42 +08:00`）。
3. **记错误码**：页面提示原文 + 若有错误码字段则记录（`AI_PROVIDER_OVERLOADED` / `AI_BUDGET_EXCEEDED` / `DATA_SOURCE_UNAVAILABLE` / `AI_NOT_CONFIGURED` 等）。
4. **记上下文**：数据源（demo/oulad）、课程/学期筛选、操作顺序、是否可复现（每次/偶尔/仅一次）。
5. **读审计**（终端，读操作，不影响线上）：

```bash
node -e "const fs=require('node:fs');const rows=fs.readFileSync('records/analysis.jsonl','utf8').trim().split('\n').slice(-50).map((line)=>JSON.parse(line));const hits=rows.filter((row)=>row.errorCode);console.log(hits.length?hits.map((row)=>[row.timestamp,row.datasetId,row.stage,row.errorCode,row.promptVersion??'-',row.model??'-'].join(' | ')).join('\n'):'最近 50 条审计没有错误');"
```

审计只含用户、数据源、计划、阶段、耗时、条数、错误码与 prompt 版本/模型，**不含问题原文与模型正文**，可以放心贴给开发者。

## 6. 回滚与恢复（只在“必须继续演示”时执行）

- **配置回滚**：AI 配置没有自动备份。改动配置前先手工复制 `records/system/`（至少 `ai-config.json`）；恢复前先停写、按 [recovery.md](recovery.md) 的备份/恢复流程操作，不要直接覆盖线上文件。
- **服务回滚**：已部署环境用 `node scripts/rollback-image.mjs`（先预演，加 `--apply` 才执行），保留当前 `records`；回退后仍需跑带认证的 smoke。
- **本地演示机**：优先重启 `pnpm dev`、重新登录、切换数据源；不要删除 `records/`、不要 `down -v`。
- 回滚完成标准：固定问题能出图、管理员能登录、AI 状态与错误码回到预期。回滚后补一条记录表。

## 7. 一页速查

| 现象 | 判断 | 现场动作 | 话术 |
| --- | --- | --- | --- |
| 请求失败/一直转圈后报网络错误 | 断网或服务不可达 | 停自由提问，切固定问题 | A |
| 429，提示服务过载/请求较多 | 服务商限流（常见 1305） | 等 30 秒，不连点，用固定问题 | B |
| 429，提示用量达上限 | 预算耗尽，请求未发出 | 不改预算，切固定问题 | C |
| 503，提示 AI 未配置/单价缺失/密钥不可用 | 配置或密钥问题 | 不现场修，切固定问题 | D |
| 503，提示数据源读取失败 | 数据文件问题，非 AI | 切换数据源 | E |
| 结果只有文字没有图/没有“数字从哪来” | 该问题命中 lookup/文本表达 | 换“比较/趋势/分布/关系”问法 | 动线 1–3 |
| AI 要求澄清 | 目标不明确（正常行为） | 按建议补课程/学期/指标 | 动线 5 |

现场只允许改三样东西：**提问内容、数据源、展示方式**。其他都不改。
