# 赛事第二阶段：受控多步分析、知识引用与真实执行过程

实施日期：2026-10-19。分支：`codex/competition-phase2`，从 `codex/ai-home-preview` 当前提交新建。保留原有未跟踪的 `app/preview/` 与 `参考.af`。本轮本地实现、测试与后续统一流程路线图随分支提交归档，未推送、合并或线上部署。

## 已实现的首版

- 对话输入新增“普通问答 / 综合分析”。普通问答保留原有规划及 JSON 响应；综合分析用标准工具调用执行有次数、总时间和共享费用预算的模型—工具循环。
- 两个适配器分别使用 Chat Completions 的 `tools/tool_calls/tool_call_id` 与 Responses 的 `function_call/function_call_output/call_id`。保留 Responses 输出项供下一轮回传；不把旧的 JSON 规划称为 Function Calling。
- 工具包括聚合统计、双学期课程比较、指定课程成绩分布、现有高级图表、知识检索和范围澄清。参数通过现有白名单和 Zod 校验；模型没有任意 SQL、文件、网络或个人明细访问权限。
- 后续分布依赖真实比较结果；程序校验“下降最多”对应的课程和目标学期。用户显式指定的比较方向优先于模型给出的方向；无下降或无共同可比课程时如实说明。图表、表格共用排序方向。
- 一条回复可含多个 `artifacts`、引用和执行记录；保留旧的单个 `artifact` 兼容字段。上下文对应最后一个结果，各附件分别切换图表/数值表，同一时刻只展开一个附件。
- 数字、最大下降、分布摘要及后续核查建议由程序根据工具结果生成；模型最终自由文本不作为已验证结论输出。不能把跨期均值变化解释成个体进步或教学因果。
- 内置 8 条有版本和适用范围的知识资料：现有指标定义自动生成，另含模拟数据、OULAD、出勤/缺勤、比较与隐私限制。使用小规模词项检索，引用指向可访问的 `/knowledge/teaching` 对应章节；无依据、版本冲突、数据源不适用时不补写知识。尚未收录学校正式规则，不提供上传或任意网页检索。
- 综合分析用 POST + `Accept: text/event-stream` 接收真实 `step` 和最终 `result/error`。未声明 SSE 的客户端仍可接收 JSON。普通问答已去掉按秒数猜测执行阶段的提示，改为中性等待文案。协议决策见 [ADR 0003](adr/0003-no-streaming-yet.md)。
- 模型与 DuckDB 共用取消信号；支持整个分析的总时间限制、重复调用检测、参数校验、多个工具调用逐项计数和已成功结果的部分返回。每次实际模型调用单独预留/结算费用，包括失败和兼容性检测。
- 审计按用户请求记录，并保存固定操作名、状态和耗时；不保存对话正文、模型输出、检索正文或原始结果行。部分成功保留明确的失败码。

## 管理与使用

系统管理 → AI 设置 → 综合分析：

1. 沿用现有模型、地址、协议、密钥、单价及预算；保存连接后点击“检测工具调用兼容性”。检测实际调用两次模型，验证工具请求及工具结果回传，费用计入原有预算。
2. 开启综合分析，并设置每轮工具次数（2–8，默认 6）及总时间（15–120 秒，默认 60 秒）。调用轮次仍受总时间与同一单次请求费用上限约束。
3. 知识库可查看资料、版本、索引更新时间及重建索引。第一版由项目文件维护资料；来源变更后不会继续返回旧的索引正文。

兼容性证据与地址、协议、模型及密钥绑定。更改其中任意一项后，旧检测结果不能用于新配置。临时网络、鉴权、单价或预算失败不被误标记为“不支持工具调用”。此次真实验收未修改现有模型连接、密钥、单价或预算，也未自动保存管理页的兼容性状态；首次使用仍需在管理页执行检测。

## 验证证据

- 常规测试：543 项通过，73 项按设计跳过（真实模型与独立 HTTP 用例）。覆盖实际 DuckDB 的动态依赖查询、错误方向修正、重复/未知工具、参数越界、总超时、取消、共享预算、缺少依据、版本冲突、源数据不可用、SSE 分块解码和请求归属等。
- 独立认证 HTTP：25 项通过。含新管理接口的账号权限、配置保存、索引重建，以及未完成工具检测时的 SSE 安全终结错误；隔离账号和状态，不调用模型。
- 类型检查、隔离生产构建和原生 DuckDB standalone 检查通过；编译器生成路径已恢复。
- 新增真实验收命令 `pnpm eval:ai:phase2`：显式加载现有私有 AI 配置，默认使用 `data/sample`，不使用跨期不可比的默认 golden 夹具。当前实际模型 `qwen3.7-flash` 已通过三项验收：标准调用闭环、比较后动态选择课程并查询分布、带引用回答与范围澄清。它不是大规模准确率结论。Responses 适配器通过协议模拟测试，本轮未另接真实 OpenAI 端点验收。
- 成功真实案例中，2025B → 2025J 的 Web前端开发均分从 72.72 降至 69.65 分，下降 3.07 分；随后查得该课程 2025J 的真实成绩分布。另用原始 CSV 独立复算 18 门课程的两期均分和去重人数，全部一致。案例使用合成演示数据，不代表真实教学效果。
- 真实验收报告写在本地 `output/ai-eval/phase2-*.json`，区分了前两次失败与后续成功。曾发现默认夹具没有共同课程、模型反转前后学期及直接文字澄清未归类，已针对性修复并保留回归用例。
- Playwright 在隔离生产预览验证管理页真实保存/重建、桌面及 390px 无横向溢出。对话 UI 使用成功真实验收结果的 SSE 回放验证多附件、执行记录、引用、停止与晚到结果隔离；浏览器回放不作为再次调用真实模型的证据。截图位于 `output/playwright/phase2-*`。
