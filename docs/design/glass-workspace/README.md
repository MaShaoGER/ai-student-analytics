## 已确认的方向

| 项目 | 用户决定及其含义 |
| --- | --- |
| 工作方式 | 逐步看预览、讨论、修改；本次按要求做阶段整理，后续继续逐项确认。 |
| 设计范围 | 允许整体重构界面布局，不必沿用现有项目的页面结构。 |
| 两种模式 | 传统图表的数据浏览与 AI 对话分为两种完整界面。 |
| 切换位置 | 在左上角放切换开关；切换时整个工作区改变。不是顶部、左侧、底部三处同时放入口。 |
| AI 布局 | 左侧保留分析历史，主要区域是统一对话流；图表、表格、分析依据放入助手回复。之前独立的对话栏与结果画布应融合。 |
| 材质方向 | 希望看到图案浮在玻璃上的感觉，增强通透、厚度、折射和色散；参考既包括磨砂玻璃，也包括纹理玻璃与流动光带。 |
| 动效方向 | 后续版本允许少量动态，以看清折射、色散和背景透过玻璃的变化。 |
| 预览方式 | 用代码绘制页面或截图，不使用图片生成。当前只做固定桌面画布，不做页面大小适配。 |
| 业务语境 | 围绕学析台的课程成绩、学习活动、匿名聚合分析和 AI 问答组织展示。 |

## V4 当前候选

V4 将已确认的两种模式与统一对话结构组合起来，以烟灰玻璃为主体，使用冷白文字、灰绿色数据图形，以及局部青蓝、紫色和琥珀折光。玻璃通过透射背景、边缘弯曲、色散、高光和厚度阴影表达；文字和图表几何保持稳定。

| 模式 | 当前预览呈现 |
| --- | --- |
| AI 对话 | 历史侧栏、对话标题、用户问题、助手结论、内嵌课程图表、结果视图切换、来源提示、追问建议和底部输入区。 |
| 数据浏览 | 数据与筛选侧栏、总览指标、课程比较、成绩分布、学习节奏和聚合明细。 |
| 共用部分 | 左上角模式开关、品牌、工具区、演示数据标识、光效播放与暂停。 |

已实现的演示交互：两种模式切换；AI 结果在图表、表格、依据间切换；折光播放与暂停。输入、发送、筛选、导出、报告与账号入口为视觉示意，不代表真实业务已接通。

当前数值、结论、分析历史和身份均为演示内容；画面中的分析步骤与“分析完成”也不代表真实 AI 执行。预览没有请求真实数据或模型服务。

### 技术与已做验证

- 固定画布：V4 为 1600 × 1000；V1–V3 为 1600 × 1120。
- HTML / CSS / SVG 绘制界面；V3、V4 用自写 WebGL 背景与材质程序模拟折射、色散，没有生成位图素材。
- V4 页面自包含；V3 需保留相邻的 `glass-overview-v3.js`。
- V4 支持 `?mode=ai`、`?mode=data`、`?t=2.4`（光效定帧）、`?reduced=1`（不透明材质预览）。
- 已在本机 Chromium 检查两种模式、鼠标与键盘切换、三种结果视图、播放/暂停、系统减少动态效果，以及 WebGL 不可用时的静态降级。
- V4 检查时页面尺寸为 1600 × 1000、没有页面裁切，WebGL 错误码为 0，浏览器控制台无错误。一次 1.2 秒观测绘制 36 帧，仅说明该次本机运行结果。
- 尚未覆盖 Safari、Firefox、真实设备、长对话、真实数据密度、完整无障碍和生产性能验证。
