# 学析台产品界面重构

日期：2026-10-23。当前状态：本地实现并完成下述检查，未推送或部署。

## 问题与目标

此前工业主题、玻璃材质和各轮组件修订同时参与正式页面的样式计算，同一种控件的外观分散在多个全局文件和组件覆盖中。用户要求按完整产品重构，使后续新增功能遵循一致规则。

本轮采用中性画布、清晰的信息层级和单一强调色。导航、标题、数据源、账号、控件状态与响应式规则统一；保留现有聚合计算、权限、历史、引用与导出能力。

## 代码归属

| 文件 | 唯一职责 |
| --- | --- |
| `app/theme.css` | 浅深主题、颜色、字形、尺寸、圆角与语义令牌 |
| `app/globals.css` | 基础元素、通用按钮/表单/面板、账号与管理表单 |
| `app/workbench.css` | 应用壳、导航、顶栏、页面标题、导航和退出弹层 |
| `app/analysis-layout.css` | 分析结果、图形选择、表格、数据档案与响应式 |
| `app/overview.css` | 总览指标、课程比较、排名与辅助入口 |
| `app/auth.css` | 登录页结构与表单 |
| `app/interactions.css` | 指针反馈、简短切换、加载与减少动态规则 |
| `components/workspace-chrome.tsx` | 各页面共用的导航、数据源、账号与移动导航 |
| 各组件的 `.module.css` | 组件内部布局，直接使用统一令牌 |

根布局仅引入上述正式样式。旧 `glass-*.css`、旧动效文件与光学渲染代码未被删除，用于保留既有工作与历史预览，但不再参与正式界面的加载。上一轮尚未提交的光学实现和配置改动未覆盖。

组件内原先以 `.glass-workspace` 为前提的重复覆盖已经并回各组件的常规规则；主界面不再挂载背景光学渲染器。保留少量兼容令牌供历史预览使用，不产生另一套产品主题。

## 交互与数据

- AI 对话与数据页面使用同一导航；取消把页面切换、账号和视觉设置堆在一排玻璃按钮里的布局。
- 顶栏集中当前页面、数据源、演示标记与主题；账号和系统管理集中到导航底部。
- 总览以准确指标和课程比较为主；图表控件紧凑呈现，必要的数据限制和散点说明保持可见。
- 统计读数直接显示准确值；不在每次切换后从零计数。控件指针操作只用短促反馈，键盘和减少动态偏好保持即时。
- 继续显示合成演示数据、分组人数不可相加、历史保留期限和来源说明。

## 验证

可重复浏览器检查：`node scripts/verify-product-interface.mjs`。它创建隔离账号和应用状态，使用真实本地接口与演示数据，显式关闭模型配置。截图和完整结果写入 gitignored 的 `output/ui-refactor/`。

检查涵盖登录、总览、分析、数据、报告、管理、账号、AI 输入与推荐问题；浅深主题；桌面、平板和390/320px窄屏；导航与退出确认；键盘关闭、草稿恢复、页面溢出与基础无障碍检查。

2026-10-23 验证结果：

- 浏览器：36项检查通过，34张截图；包含账号管理、数据集/导入、操作日志、AI设置，以及390/320px导入界面与管理指标卡。
- 基础无障碍：17处检查未发现自动违规；学科全景SVG和导入预览仍有需要人工判断的对比度项，此结果不代表完整无障碍认证。报告检查范围为新控件区，独立报告文档由导出回归覆盖。
- 相关回归：31项通过，覆盖结果附件、图形语义和导出。
- TypeScript检查通过；独立输出目录的生产构建通过，包含41个编译路由。
- Next.js开发服务器未记录配置或浏览器运行错误；真实本地接口返回推荐问题的聚合结果，模型调用数为0。

浏览器仿真不代表已验证真实手机键盘、触感、安全区、真实模型质量或线上部署。
