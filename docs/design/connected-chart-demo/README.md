# 连续图表滚动样例

打开 [index.html](index.html) 即可查看。页面完全自包含，无需安装依赖，也可直接在浏览器打开文件。

这是对“图表在画面中物理连接”要求的第一份实际前端样例：

- 四根柱子向下弯成四条趋势线。
- 趋势线通过连续路径接入热力图的四行。
- 四行从另一侧延伸，接入课程关系网络。
- 所有图形共用一个 SVG 坐标系；静态时已连接，浏览器原生滚动时亮光沿连接线移动。
- 支持正常回滚、章节锚点、减少动效和系统减少动态效果偏好。

固定示意数据用于构图与交互验证，连接路径不表示统计推导。热力图及关系网络处均标注统计视角的变化。

预览：`python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/design/connected-chart-demo`。

## 静态样例 02

[PNG](static-study-02.png) · [可编辑 SVG](static-study-02.svg)。在原型基础上统一了连线含义：一种颜色的线始终代表同一门课。

- 01 → 02：柱子末端的本学期均分，落到 02 哑铃图的本学期一端，数值不变。
- 02 → 03、03 → 04：指标或统计对象改变时，线在虚线分界处断成像素，再接到下一张图，分界处标明换了什么。
- 课程色改为四种明显不同的色相（紫 / 绿 / 橙 / 蓝），并配有阅读图例；每张图都有自己的刻度或说明。
- 04 的节点按低于 70 分的人数重新排序，C–D 共同薄弱 18 人这一对单独突出。

数据为固定演示数据，四张图之间数值一致；连线是阅读路径，不表示统计推导。

## 互动预览：切片 1（01 → 02）

启动 `next dev` 后访问 `/preview/connected-story`（代码在 `app/preview/connected-story/`，noindex，不影响正式首页）。

- 文字与两张图均为 HTML，连线在覆盖层 SVG 中，端点按实际布局测量，窗口尺寸变化时重算。
- 滚动只做逐步揭示：柱子生长，线沿阅读路径落到 02 的本学期一端，再展开到上学期；停止滚动即停住，回滚倒放。
- 悬停、轻触或 Tab 选中一门课，两张图同时标出它，读数用 HTML 文字显示；轻触或点击可固定，再点一次取消。
- 关闭动效或系统减少动态效果时，直接显示完整且已连接的静态图。
- 指标切换（均分 / 及格率 / 优秀率、上学期 / 前两学期）尚未实现。
