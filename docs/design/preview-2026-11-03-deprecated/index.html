🎯 核心设计特性

🎨

暖白画布

#f5f5f2 暖白底 + #232329 接近黑文字，保持清爽与可读

💜

淡紫强调

#7666cc 少量点缀，用于选中、焦点、图形主线，保持克制

✨

玻璃材质

15px 背景模糊 + 半透明渐变 + 顶部白光 + 底部紫边

👁️

边缘虚化

中心清晰、外围渐进虚化，用于图表、全览、过渡动画

🔄

混合圆角

按钮/标签 999px 胶囊，容器 0-12px 直角或微弧

⌨️

焦点发光

紫色边框 + 微妙光晕 + 平滑 0.2s 过渡，不生硬

📊

等宽数字

font-variant-numeric: tabular-nums 对齐表格数据

🌌

空间透视

rotateX(6deg) 俯视 + 鼠标位移 + 历史堆叠 + 远层虚化

📋 设计决策汇总

主题色体系

基础紫 #7666cc
浅紫 #dcd6ee
透明紫 rgba(118, 102, 204, 0.15)

圆角策略

按钮：999px
卡片：0-4px
浮层：12-16px

动画参数

快速过渡：150ms
进入/离开：300-400ms
缓动：cubic-bezier(0.22, 1, 0.36, 1)

模糊效果

玻璃：blur(12-15px)
装饰：blur(2-4px)
过渡：blur(0-12px)

优先级实施

1️⃣ Token + 基础
2️⃣ 数据浏览
3️⃣ 其他页面

验收标准

✓ 静态画面接近
✓ 图表响应数据
✓ 浏览器实截图
