✓ 焦点边框：2px 紫色 #7666cc

设计系统特点总结

  • 🎨 暖白底色 #f5f5f2 + 近黑文字 #232329
  • 💜 淡紫强调 #7666cc（少量点缀，非主色）
  • 🔄 混合圆角：按钮/标签 999px，容器 0-12px
  • ✨ 玻璃浮层：背景模糊 12-15px + 渐变 + 高光边
  • 👁️ 边缘虚化：径向渐变 + 轻 blur 呈现空间感
  • ⌨️ 焦点反馈：紫色边框 + 微发光 + 平滑过渡
  • 📊 等宽数字：font-variant-numeric: tabular-nums
  • 🎯 状态清晰：小样本灰化、加载脉动、成功绿色
