# 黑白、光感玻璃与边缘模糊：HTML 设计预览

建立日期：2026-11-03。依据[设计语言总纲](../ai-frontend-reference/design-language.md)制作的独立 HTML 样例，不改动正式应用。

## 打开

本机预览：`http://127.0.0.1:8766/`。若服务器已停止，在项目根目录执行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/design/ai-frontend-preview
```

也可以直接打开 `index.html`；CSS 和脚本采用相对路径。字体尝试从 Google Fonts 加载，未联网时使用本机中文字体。

## 可以体验什么

- 点选六门课程，关系图焦点、课程均分、通过率和趋势同步变化；“查看课程”进入六指标详情，能返回原浏览模式。
- 切换“空间全览”，观察斜侧平行叠层与远层虚化；点选图层聚焦，再次点选进入课程。前后按钮和左右方向键切换主题，首尾不循环。
- 右下“调整光感”控制边缘模糊、光感与色散，并可试用四种主题色。紫色只是初始候选。
- 右上切换明暗；右下动态按钮和系统减少动态偏好共同控制动画。Esc关闭设置、返回课程或退出全览。

## 表现与范围

- 共享画布与黑白为主体，半透明玻璃操作层带局部光谱边缘、柔光和高光。
- 图形外围使用带渐变遮罩的背景模糊，远层按距离失焦；滑块能调节实际模糊强度，不只改变颜色或透明度。
- 玻璃是 CSS 视觉近似，未声称物理准确折射。课程、人数、百分比、趋势和关联均为明确标注的固定示意数据，不调用正式API。
- 空间全览中的六个课程层是构图样例，不表示已经接入正式探索历史。
