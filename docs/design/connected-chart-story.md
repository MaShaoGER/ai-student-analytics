# 首页连续图表叙事方案

日期：2026-10-30  
状态：历史首页叙事候选，六段分镜及物理连接样例不作为当前正式功能清单。

资料定位更新（2026-11-02）：本文件保留 2026-10-30 的规划与原型记录。主项目现有连续浏览和群体探索见[工作台指南](../workspace-guide.md)，不以静态样例、互动切片或下文“待验证”推断正式页面的实现状态。

物理连接原型：[可直接打开的 HTML](connected-chart-demo/index.html) · [完整截图](connected-chart-demo/preview.jpg)。根据后续澄清，先制作柱状图 → 趋势线 → 热力网格 → 关系网络的连续 SVG 样例：图形端点在同一画面直接相接，原生滚动时光段沿已有路径移动。此样例独立于正式页面，下面六段规划仍为候选内容。

## 1. 核心体验

首页的主要内容是一幅纵向展开的连续数据画卷。访客通过浏览器正常滚动，依次看见课程差异、成绩分布、学期变化、学习节奏、行为关系与学科联系。图表共享网格、课程识别色和一条贯穿画面的引导线，形成一个整体。

打开页面时，第一张主图已经完整可见，下一段图形与连接线从屏幕下沿延续出去。静态画面本身就有连接关系，滚动只负责逐步揭示和细化。无需点击开始、拖动场景或等待开场动画。

本方案延续白底、像素装饰、局部柔光、常规字重中文和开放式排版。它调整第四版首页的内容优先级：连续图表成为首页主叙事，问题输入、功能清单和报告预览在画卷结束后承接。

## 2. 连续构图

- 首屏左侧用两行标题和简短说明讲清产品用途，右侧是可读的课程比较主图。主图中的一条参考线向下延伸，露出下一段图形；不是把六个图表缩成六张卡片。
- 整条画卷以同一套列网格对齐。图形可以左右交替展开，标题与一句发现放在留白中；段落之间不设置厚重容器。
- 用一条很细的“发现线”贯穿场景。它是阅读引导，不是数据曲线；使用淡色、独立位置和少量微光与图表区分。
- 数据视觉与装饰分层。课程识别色跨章节保持稳定；章节强调色和柔光可以变化。成绩、时间和频数的坐标轴始终有各自标识。
- 前一图尾部与后一图开头在过渡区可以同时可见。通常只让一张主图承担阅读任务。
- 每段保留一个稳定、完整的图表状态，让访客停下滚动时能真正读懂图，而不只看到中间变形。

## 3. 建议的六段主线

图表依据项目已有的能力文档选择；本阶段用统一的虚构演示数据制作，暂不要求后端配合。六段是首版分镜建议，不是必须把所有图表装入首页。

| 段落 | 访客关心的问题 | 主图与画面 | 与下一段的连接 |
| --- | --- | --- | --- |
| 01 看见差异 | 哪些课程表现不同？ | 4–5 门课的均分柱状图，课程名和均分直接可读；少量像素作为图形的构造细节 | 选定课程的均分标记保留，旁边展开其成绩分布；同一成绩刻度衔接到下一段 |
| 02 看见分布 | 均分背后，有怎样的差异？ | 同组课程的分布与箱线图；用一个明确标注的局部点阵示意解释四分位范围 | 同一课程的颜色和名称延续；引导线把视线带到两个学期的比较，明确标注统计范围变化 |
| 03 看见变化 | 这门课和上学期相比如何？ | 两学期哑铃图；一端为上学期，一端为本学期，显示差值 | 时间标记向下展开成周次；新的一段标明从“成绩”转为“每周学习活动” |
| 04 看见节奏 | 学习活动集中在哪些时段？ | 课程 × 周次的热力图；网格从页面装饰自然成为实际图表，但使用独立图例 | 聚焦同一课程，保留高亮标签；下一段引入活动量与成绩两个轴，展示其联合分档统计 |
| 05 看见关系 | 活动量与成绩呈现怎样的联系？ | 分档散点图：位置表示活动量与成绩区间，点大小表示选课人次；高亮一处群体特征 | 沿引导线转到学科视角，明确更换统计对象；课程标签重新组织成圆弧，关系带单独绘制 |
| 06 看见全貌 | 哪些课程的薄弱表现共同出现？ | 学科关联弦图，先突出一对课程，再呈现其余关系；旁边用一句话解释连线含义 | 弦图的轮廓在收尾处形成报告中的缩略图；出现“开始探索你的问题”入口 |

建议开屏文案：“从一个差异，看见更多可能。”结尾：“这些发现，可以从你的一句话开始。”文案用于表达叙事，未定稿。

## 4. 转场设计：哪些可以变形，哪些应当衔接

### 可以连续变形的部分

- 同一课程的均分点与其分布可共享成绩刻度，均分点保持为均分点；中位数以独立标记出现。
- 同一课程、同一指标、相同刻度的前后学期标记，可以沿数轴移动或扩展为哑铃图。
- 装饰网格可以逐步显现为热力图布局，但装饰单元在出现数值含义前不标为真实数据。
- 课程标签、辅助线、光带、图表轮廓可以在场景之间保持形态联系。

### 应当明确交接的部分

- 均分不能拆成任意数量的“学生点”，柱形面积不等于学生人数。
- 周活动热力图与活动量—成绩散点使用不同聚合口径，不让每个热力格直接变成一个人或一个散点。
- 课程关系弦图采用两门课共同低于阈值的频数或占比，不能从上一幅活动量散点直接推算。
- 指标或人群变化时，用短标签、轴标题和旧图退出／新图进入交代变化；视觉连接不暗示因果。

“顺滑”主要来自保持构图锚点、颜色和阅读路径，不要求所有数据标记彼此一一变形。

## 5. 正常滚动的具体规则

- 页面按真实文档高度上下滚动，滚轮、触控板和手机滑动都使用浏览器默认行为。
- 图表分布在纵向文档中；首版不采用整段长时间固定同一画面的方式，也不拦截滚轮切换场景。
- 动效进度跟随当前场景在视口中的位置。下滚展开，上滚回到对应状态；快速跳过仍能直接呈现相应结果。
- 每段按“进入与引导约 20% → 完整图表阅读约 60% → 衔接约 20%”分配滚动距离；这是分镜比例，不是固定播放时间。
- 停止滚动后，主体图表与文字停止变化；柔光可有极轻微独立呼吸，关闭动态效果时全部静止。
- 首屏立即显示主图与标题。首次进入可有很短的淡入，不以空白和长倒计时制造期待。
- 数据提示可在桌面悬停、键盘聚焦或手机轻触时补充，核心标签与结论直接可见。
- 图表旁的小标题锚点允许直接跳到某段，始终保持正常阅读顺序。

## 6. 节奏与篇幅

建议六段主线约占 6–8 个桌面视口：首屏约 1 屏；其余每段约 0.8–1.1 屏；通过少量重叠的过渡区连接。画卷之后再安排简短的演示入口、功能说明与报告成果。滚动长度以分镜预览验证，不强行拖长。

视觉高潮建议放在第 04 段的热力网格铺展和第 06 段的关系弧线汇合。其余段落用轻量聚合与位置过渡维持节奏。避免每段都采用大幅旋转、爆炸或全屏缩放。

如果六段仍显冗长，优先将箱线图作为柱状图的同段展开、哑铃图作为热力图之前的短插段，形成“比较与分布 → 时间与节奏 → 行为关系 → 学科全貌”的四章版本。

## 7. 桑基图与其他图表如何纳入

桑基图视觉上很适合连接，但它的实际含义是出勤档位 → 作业完成档位 → 成绩档位的群体路径，不代表学生沿时间迁移或因果链。

建议把它保留为第 05–06 段的替代结尾：若希望主线讲“不同学习行为组合”，选择桑基图；若希望讲“课程之间的联系”，选择弦图。首版不同时加入两张复杂关系图。折线图可以在强调多学期趋势时替换两期哑铃图，而不是为图表数量额外增加一章。

## 8. 移动端与静态版本

- 移动端使用单列：一句问题、主图、一句发现、连接到下一段；课程数量适当减少。
- 保留纵向连接线和像素母题，缩减画面横向迁移，标签在换行后仍有独立空间。
- 减少动态效果或视觉资源未就绪时，直接展示同样已连接的完整静态图表。
- 正文不逐字打散，图表不依赖精细悬停才能理解；长图可以顺畅回看。

## 9. 下一步制作顺序

1. 确定演示课程、两个学期及每幅图的口径，生成相互一致的固定统计结果。
2. 先画一张连续长分镜，检查全部图表在静止时是否已经连成整体，确认章节和篇幅。
3. 选择“柱状图 → 分布”和“热力图 → 分档散点”两处做短动态原型：分别验证可共享刻度的变形与不同指标的交接。
4. 全部接入正常滚动，再加入局部柔光、像素细节和交点微光。
5. 检查停下、回滚、快速滚动、手机滑动与减少动态效果时的阅读体验。

验收重点：能看懂连续的数据故事；图表中的数据含义清楚；静态已连接；滚动顺畅；视觉重点有起伏。

## 10. 实施路线（2026-10-31）

静态样例 02 验证了四章构图与连线规则。互动版在独立预览路由 `app/preview/connected-story/` 实现，不改正式首页。

配色收紧：课程身份靠位置与标签区分，线默认墨灰；每章只把该章主角染成色板强调色。选中一门课时，它在全页的线与数值以柔紫高亮，其余降到低透明度。

结构：文字为 HTML；每章一个独立 SVG；连线层覆盖在章节之上，端点从各图锚点实时测量，窗口尺寸变化时重算。关闭动态效果或系统要求减少动态效果时，直接显示完整的已连接静态图。
