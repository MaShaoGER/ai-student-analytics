## 边界和遗留

- 本轮不是上线、真实设备或性能容量验收。生产构建不等同于已部署；浏览器手机宽度模拟不等同于真机。
- 权限撤销在下一次服务端请求立即检查；已打开页面在下次焦点/可见性或 45 秒会话与画像校验时清理，不能撤回本地已下载内容。
- CLI/评测属于受信任服务端调用，没有 HTTP 授权上下文；以后新建业务入口必须建立统一授权上下文，不可直接裸调用查询或模型服务。
- 全站概览只汇总有明确记录的分析请求；图表/画像 GET 不计作全部 HTTP 请求。旧记录、坏行、读取上限、测试/评测可能混入与估算费用均在页面披露。
- 目录可用性检查必需源文件存在、可读且为文件，不保证 CSV 内容质量或每一种可选字段能力；声明版本不是动态内容哈希。
- 管理日志与所属业务状态同一事务提交，损坏的当前审计格式拒绝高权限变更；不覆盖原分析记录。账号管理的受保护目标拒绝会记录固定失败码；前置验证与配置保存失败不承诺全部进入管理事件日志。
- 原有 AI 九项真实语义评测失败记录继续有效。本轮没有修复或改判这些失败，也未重跑付费模型评测。

本轮隔离端口 3201 服务、临时账号状态及临时凭据已清理，测试和构建目录保留作为本地验收产物；没有停止其他服务。`next-env.d.ts` / `tsconfig.json` 已恢复为开始验收前的原内容，保留用户原有改动，恢复后再次类型检查通过。

验收完成后，用户授权将全部成果一起本地提交，包含后台、既有 AI 回答可靠性修正、预览页和 `参考.af`。本机生成的编译路径、运行时状态和密钥不进入提交；未推送、合并或部署。
