# AI 配置交接单（一页版）

用途：管理员换人、换机器、换服务商时，照这一页交接即可。读完应能回答四个问题：**谁能改、密钥在哪、钱怎么算、出事找谁**。

相关文档：[工作台使用指南](workspace-guide.md)｜[百炼接入](bailian-qwen.md)｜[智谱试用](zhipu-glm.md)｜[备份与回滚](recovery.md)｜[演示预案](demo-runbook.md)｜[隐私与 AI 边界](../README.md)

## 1. 谁有配置权

- **只有管理员**能进入“系统管理 → AI 配置”：代码在 `lib/auth/http.ts` / `app/api/admin/*` 校验 `role: "admin"`；管理员创建的账号只能是普通用户（`role: "user"`），不能自行提权。
- 管理员账号由 `pnpm admin:init` 在终端创建（密码至少 12 位），没有默认密码、没有网页注册。
- 普通教师：可提问、可看分析结果，**看不到密钥、改不了模型/预算**，也没有管理页入口。
- 交接原则：**管理员账号、`APP_SETTINGS_KEY`、服务商控制台账号**三者由不同人或不同保管位置持有，任一方丢失都不会同时丢数据和密钥。

## 2. 密钥与配置文件放在哪

| 对象 | 位置 | 说明 |
| --- | --- | --- |
| 加密主密钥 `APP_SETTINGS_KEY` | `.env.local` 或私有运行环境（Docker 的 runtime env） | 32 字节 base64。**不在 `records/` 内**，必须单独备份。换掉它，已有 `ai-config.json` 里的密钥就解不开。 |
| AI 配置 `records/system/ai-config.json` | `records/system/`（Docker 持久卷） | 模型密钥以 AES-256-GCM 密文保存（`iv` / `tag` / `ciphertext`），另含模型、协议、基础地址、预算、单价。页面只返回“是否已配置”，不返回密钥。**仓库没有自动配置备份**：换模型/换服务商前请手工备份整个 `records/system/`。 |
| 用量记录 `records/system/cost-history.json` | `records/system/` | 估算费用与调用记录（USD）。 |
| 分析审计 `records/analysis.jsonl` | `records/` | 不含问题原文与模型正文，见第 5 节。 |

交接动作：

- [ ] 用私有渠道分别交付 `APP_SETTINGS_KEY` 和 `records/` 备份，**不要**把密钥写进工单、聊天、Git 或文档；
- [ ] 交接后立即验证：管理员能登录、AI 配置能解密（点“测试连接”返回有效计划）、`records/system/ai-config.json` 已在接管方的备份中；
- [ ] 旧管理员账号按需停用；停用会立即撤销其会话。

## 3. 模型 / 协议 / 单价 / 币种 / 汇率口径

当前配置（以管理页实际保存值为准）：

| 项 | 当前值 | 备注 |
| --- | --- | --- |
| 模型 | 百炼 `qwen3.7-flash`；备用智谱 `glm-4.7-flash`（免费） | 切换步骤见各自接入文档 |
| 协议 | 百炼/智谱：兼容 `chat_completions`；OpenAI：`responses` | 基础地址不要追加 `/chat/completions` |
| 基础地址 | 百炼：`https://业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`；智谱：`https://open.bigmodel.cn/api/paas/v4` | 留空 = OpenAI 官方 |
| 计价单位 | **USD / 百万 token**（输入、输出分别填） | 管理页与用量统计统一 USD |
| 单价口径 | 估算单价，不反映缓存折扣、免费额度或服务商最终账单 | 账实差异是已知边界，不是故障 |
| 汇率口径 | 人民币单价 ÷ 每美元对应人民币金额 = 填入的 USD 单价 | **汇率不落盘**，必须在下方交接记录里手写“日期 + 汇率”，否则换人无法复核 |

交接记录（手写，必填）：

```text
汇率基准：1 USD = ______ CNY     记录日期：__________      数据来源：__________
输入单价：______ USD / 百万 token       输出单价：______ USD / 百万 token
服务商后台免费额度/扣费策略：____________________________________
```

## 4. 预算四项与行为

| 预算 | 默认值 | 行为 |
| --- | --- | --- |
| 单次 `perRequest` | 0.1 USD | 一次提问的规划+解读合计上限 |
| 每小时 `perHour` | 5 USD | 滚动小时窗口 |
| 每天 `perDay` | 20 USD | 滚动 24 小时 |
| 30 天 `perMonth` | 200 USD | 滚动 30 天 |

- 调用前**原子预留**估算费用，实际用量结算后回补；超限返回 `AI_BUDGET_EXCEEDED`（429），本次请求**不发给模型**、不产生新费用。
- 不自动重试收费调用；“测试连接”同样计入用量。
- 零单价模型（智谱免费版）仍受平台限流与应用请求限流，预算不限制请求数量。
- 免费额度不能代替服务商扣费限制：建议在服务商控制台开启“免费额度用完即停”。

## 5. 审计保留与隐私边界

**记录**（`records/analysis.jsonl`）：用户、数据源、分析计划（指标/维度/筛选/图表）、阶段、耗时、结果条数、安全错误摘要、`promptVersion`、模型名。

**不记录**：问题原文、对话正文、模型回复正文、结果明细、学生标识。

**不返回 / 不处理**：学生个人名单与排名、家庭收入等未接入字段、任意 SQL、写操作；少于 3 人的分组不展示，只输出群体聚合。

**保留策略**：审计按追加写入，当前无自动归档/清理调用；长期需分片或归档（已知待办）。成本记录目前没有按人归集（`CostRecord` 无 `userId`），只能看总账——这是已知边界，交接时不要承诺“按老师统计费用”。

## 6. 交接检查清单

- [ ] 管理员账号可用；普通账号不可进系统管理；

- [ ] `records/system/`（含 `ai-config.json`）已手工备份；知道怎么回滚（恢复同一 `APP_SETTINGS_KEY` 才能解密）；

## 7. 验收命令（交接后当场跑一遍）

```bash
pnpm typecheck
pnpm test
pnpm test:api          # 启动隔离服务，不调用真实模型
node --test scripts/recovery.test.mjs
pnpm build
AI_EVAL_MOCK=1 pnpm vitest run scripts/ai-eval.test.ts   # 评测用例结构校验，不花钱
```

真实模型验收（可选，会产生费用）：

```bash
# 管理员页面：保存配置 → 测试连接 → 必须返回有效分析计划
AI_EVAL=1 pnpm vitest run scripts/ai-eval.test.ts         # 生成 output/ai-eval/<时间戳>.json
```

通过标准：测试连接返回有效计划；测试/构建全绿；评测报告写出 `promptVersion` 与模型名（报告在 `output/`，已忽略，不提交）。真实调用没有证据时，只能记录“本地适配通过”，不能记为“AI 验收完成”。

## 9. 三类常见切换（照做即可）

1. **换模型（同服务商）**：先手工备份 `records/system/`（仓库没有自动配置备份）→ 管理页改模型名 → 按新模型重新填单价（或 0）→ 保存 → 测试连接 → 记录模型名/单价/日期。
2. **换服务商**：改协议、基础地址、模型、密钥、单价 → 保存 → 测试连接 → 更新第 3 节与 `docs/` 中“当前模型”描述 → 重跑 `AI_EVAL_MOCK` 与（可选）`AI_EVAL`。
3. **换管理员**：按第 6 节清单交接；`APP_SETTINGS_KEY` 与 `records/` 备份分开交付；最后停用旧账号（立即撤销会话）。
