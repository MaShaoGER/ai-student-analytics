# AI 图表能力扩展

2026-10-18，分支 `codex/ai-chart-capabilities`，基于 `c375dea`。保留旧 `/api/ask`、原指标、报告、图表工坊与原有对话结果。

## 可以直接请求的图表

| 请求 | 数据与默认范围 |
| --- | --- |
| 成绩箱线图 | 学生-课程-学期有效成绩先取均值，再计算五数概要；支持多课程，默认最新学期 |
| 桑基图 | 模拟校园数据的出勤档位 → 作业完成档位 → 成绩档位，路径满足小样本要求；不是因果或时间流转 |
| 学期对比哑铃图 | 两学期课程均分与变化，默认所选学期与其前一期；可明确指定两个学期、课程集合和变化排序 |
| 学习节奏热力图 | 各课程每周有记录学生的人均学习活动次数 |
| 关系散点 / 密度图 | 模拟校园数据支持缺勤课时、旷课课时、出勤率或活动量与成绩的分档频数；OULAD 使用活动量与成绩 |
| 学科关联弦图 | 同学期两门课同时低于阈值的人数、共同选课有效样本及占比；默认阈值 60 分 |
| 学科全景图 | 同学期成绩分布、均分、及格率与薄弱共现的统计快照 |

明确命名这些图表时直接选择已有统计工具，不再让模型判断自己是否“有绘图能力”；界面复用既有原生图表组件。解释图表含义的普通问答仍交给模型。新增工具结果以确定性数值摘要配合图表展示，不额外调用模型生成解读。

## 按分析目标选择回复形式

用户无需知道图表名称。对话先识别概念说明、单值查询、比较、趋势、分布与关系，再结合当前问题选择文字、图形或表格；当前问题优先于上一轮的表格显示偏好。

| 问法示例 | 默认回复 |
| --- | --- |
| “这个指标是什么意思”“谢谢” | 简短文字，不附统计表 |
| “最新学期高等数学平均成绩是多少” | 真实数值与样本量的短句 |
| “比较各门课的成绩” | 柱状图和简短摘要 |
| “高等数学各学期的变化趋势” | 按学期排序的折线图 |
| “比较各门课的成绩分布” | 箱线图 |
| “那我想看看这个缺勤次数与成绩的关系图” | 继承课程和学期，返回缺勤课时与成绩的关系散点图 |
| “用表格列出各门课的成绩”或课程×学期交叉明细 | 数值表 |
| “只用文字概括” | 只显示短文字，保留上下文供后续改成图表 |

普通关系问题默认散点图，点大小表示选课人次；明确要求密度图时使用密度视图。表格和图形使用同一聚合快照，可继续切换。常规数值查询直接由实际查询结果生成短摘要，只有明确要求解读数据时才额外调用模型解释，并继续执行预算、取消与数字校验。

缺勤使用真实出勤明细：`缺勤课时 = 请假缺席课时 + 旷课课时`，单独询问旷课时不含已批准请假；单位是 45 分钟课时，不是请假单或缺勤事件次数。成绩先按学生-课程-学期去重，关系结果只返回满足样本要求的分档频数，缺失不补零，不返回学生标识。文字中的相关系数是按可见分档及频数估算，受分档和小样本抑制影响，不等同原始个体数据的精确相关系数，也不代表因果。OULAD 没有缺勤字段时明确说明，不能用学习活跃度替代。

这些工具的结果均支持消息内图表/数值表切换、历史收起/重开与“改成表格/改成图表”追问。表格与图形使用相同结果快照；点击展示切换不会重新调用接口。自然语言追问会按现有规则重新执行受限统计。

## 查询与建议改进

- 模型计划支持课程集合、学期集合及课程×学期两个维度。当前问题明确提及的数据完整标签优先于模型遗漏的筛选；最新/上一学期由数据目录与上下文解析。
- 普通自由查询默认最多返回 100 个分组，不再由模型任意猜测一个返回条数；明确的“前 N 项”仍遵循一到一百的执行上限。固定推荐问题继续使用原有已验证计划。
- 双维度要求、所有学期与筛选清除会保留对应统计范围；对不存在的学期、未知模型标签或超出工具表达范围的请求返回具体澄清，不执行替代范围。
- “从某学期到另一学期提升多少分”使用真实两期聚合并计算后期均分减前期均分，保留明确方向；不同选课群体的差值不代表同一批学生的个人进步。
- 弦图/全景仍最多展示十二科，明确请求的课程会优先进入候选，避免被原来的样本排序截掉；未达样本要求时说明缺少数据。
- 不合适的均分饼图仍生成柱状图并说明原因，不把均分伪装成可相加的占比。
- 继续探索按钮来自可执行的本地动作，不直接采用模型自由生成的建议。
- 对非工具动作，归一化不参与执行的 tool/threshold 元数据；辅助 goal 无效时回到本地语义判断。仅把已知的 lookup/compare/trend/explain/relationship 目标别名映射回合法动作，避免 JSON 服务商混淆两个字段而误拒绝合法查询；指标、范围和工具参数仍严格校验。规划说明允许为空，不影响合法计划执行。

## 继续保留的边界

- 模型不提交 SQL；统计仍由白名单字段与固定只读查询执行，认证、同源、共享限流、预算、资源上限与取消继续生效。
- 桑基图固定使用已有校园三层路径，OULAD 缺少相关字段时明确说明。关系图固定使用当前列出的四种指标与成绩，不开放任意字段/任意代码；缺勤尚未成为普通 AnalysisPlan 的通用指标。
- 新增工具均按单个学期统计；哑铃图比较两个学期。多学期逐期箱线图、任意维度关系图与其他衍生指标尚未实现。
- 学科全景在对话中展示统计快照与数值表；人群联动仍使用原“指标分析 → 学科全景”。弦图保留图上聚焦及关联详情选择。
- 高级工具快照暂未扩展到旧报告导出契约，原有分析结果的报告能力保留。
- 用户明确要求的模型自由文本解读仍可能违反语义约束或触发数字拦截后回退；日常查询已改用确定性短摘要，但本轮未宣称模型解读质量全面解决。多会话持久化、历史结果引用、流式输出和任意图表编排仍待开发。
