# 学析台工作台与账号管理

使用说明更新于 2026-11-03。本文描述当前本地功能；文末验收表保留各自执行日期，不代表全部检查每轮重跑。资料分类见[文档导航](README.md)，线上环境需另查[部署记录](deployment.md)并现场核实。

## 首次使用

```bash
pnpm admin:init
pnpm dev
```

初始化在本地或服务器终端进行，不开放网页注册入口，也没有默认密码。脚本会读取当前目录的 `.env.local`；环境变量优先。设置账号和至少 12 个字符的密码后，从登录页进入工作台。已有管理员时，初始化脚本拒绝覆盖。

也可通过 `ADMIN_USERNAME` / `ADMIN_PASSWORD` 在首次启动时初始化。创建完成后可移除这两个环境变量；已有管理员不会被环境变量覆盖。

## 页面与权限

| 页面 | 已实现 | 尚未开放或适用边界 |
| --- | --- | --- |
| 数据浏览 | 单图阅读、课程／指标／关系循环、点击后二级选择、按需指标表、同数据换画法、前后页、双轴全览、URL 与阅读位置恢复 | 按数据源字段开放能力；缺失与小样本不补零、不回退全体，不是任意业务表建模 |
| 分析工具 | 指标分析、图表工坊、结果搜索与排序、图表/表格、CSV 和报告导出 | 原工具按全体数据查询，不携带探索群体；任意业务表自动建模未开放 |
| 智能分析 | 连续追问、停止与重试、账号历史、聚合结果及依据、图表/数值表与导出 | 自由问答需可用模型和权限；历史以最后真实消息更新后 10 天为保留期限 |
| 报告中心 | 本次页面会话的结果选择、预览、CSV/HTML 下载、打印另存 PDF | 服务器历史报告、模板和分享未开放；不等同于 AI 对话历史 |
| 系统管理 | 三角色账号、数据集授权、AI 配置与预算、总览和日志、Excel/CSV 成绩导入与版本 | 组织树、自定义角色、多租户及课程/班级级授权未开放 |

管理员、分析人员和只读人员按角色与数据集授权访问页面和 API。只读人员可查看获授权的标准聚合图表，不能调用 AI 或使用产品导出；管理员可维护账号、目录和成绩导入。数据集级授权已实现，课程/班级级授权尚未开放。具体矩阵见[后台管理](admin-management.md)，导入格式与上限见[成绩导入](grade-data-import.md)。

切换数据源会重新查询，不混合来源、课程或分母；异步旧请求不会覆盖新来源的结果。数据浏览中的同范围图表复用聚合结果；精确数据表不会为缺失值补零。分析工具的搜索与排序仍只操作当前返回的最多 100 个分组。少于 3 人的分组不展示，也不输出个人记录。

默认页面使用直白文字，字段类型、指标口径和 SQL 放入可展开的专业详情。没有真实依据时不展示涨跌趋势、异常数量或历史报告。

### 连续探索

登录后从课程全景点选课程，先打开二级选择，再明确进入“数据结构”。阅读页以大标题、简短范围和一张主图为中心；“画法”“去向”“数据”三个轻量入口按需打开选择或详情。柱形、点位和雷达表达同一课六项数据。完整统一指标表、定义、单位与贡献学生样本在“数据”中可查：出勤按总课时加权，作业按应交总份数加权，“贡献样本”不是课时／作业分母。

点图中的“出勤率”，二级选择显示出勤—成绩、出勤—通过、出勤—教学周、出勤—学科等去向，并将其与“同一份数据换画法”分组。明确选关联才进入新主题；明确选学科关系才扩大到课程比较，再点另一门课可重建课程中心。打开、浏览候选或取消不改变原图、滚动位置或探索历史，Esc 关闭后焦点返回图元。课程、指标和关系可以继续循环，不自动交集筛人。课程目录最多100门，说明总数与展示数，直接打开的有效课程即便不在默认前100内也保留。

查询由 `/api/concept-explorer` 在当前账号与数据集权限内完成，学生 ID 只在服务端处理中，不进入 URL 或响应。少于3人的课程和出勤分组隐藏；空组、缺失和真实0分分别处理。OULAD无校园出勤／作业，成绩导入按真实字段启用成绩、通过、完成能力，不挪用模拟数据；教学目标达成率没有定义时明确“未配置”，不拿课程完成率冒充。

URL 保存数据集、学期、课程、指标、关系和画法。主题跳转新增步骤，换画法只替换当前条目；页面下方“上一页／下一页”沿探索条目阅读，不跳出工作台。全览横向保留看过的画法，首页固定，最近5个主题展开，较早主题可取回。返回旧主题继续不会删除后续探索。刷新、原生前进后退与 AI 往返按条目恢复阅读位置。无效／显式空地址报错并提供回首页入口，不静默换课或创建对话。

请求可取消，迟到结果不能覆盖新场景；失败可原位重试，加载不会显示旧课读数。新数据到达后短暂模糊聚焦，静止时文字与数字清晰；应用或系统减少动态即时生效。窄屏图表与表格在局部横向滚动，四角入口不挤占数据宽度；Tab／Enter／Space可操作图元，全览支持Esc、原生焦点约束和关闭后焦点恢复。

右上菜单保留数据源、原指标分析／工坊、报告、账号与管理；原工具按全体数据查询。右下进入AI时显示可移除的浏览范围，保留输入草稿，不自动调用模型、不自动新建对话。移除浏览参考不清空原对话上下文。真正发送时范围随问题交给现有AI链路；隔离验收环境关闭模型，未在线验收真实生成。


## 导出当前分析

在指标分析场景点击“预览当前报告”后进入报告中心；有导出权限时也可直接下载该结果 CSV。原分析工具和智能分析的结果继续可用于报告。总览图表不会自动打开报告。报告包含数据来源、指标口径、统计周期、每组样本数、样本过滤说明和实际查询；只比较本次查询返回的分组，不将各组人数相加当作独立学生总数。

CSV 使用 UTF-8 编码并附带 BOM，方便 Excel 显示中文。课程/学期等文本进行公式防护；以公式符号开头的文本会增加前导单引号。

报告可下载为独立 HTML 文件，或点击“打印 / 另存 PDF”，在浏览器打印界面选择“另存为 PDF”。当前报告列表来自本次会话，刷新、退出或切换数据源会清空相应结果；服务器的分析审计记录仍保留。报告分享和服务器历史报告尚未开放。

## 查询保护与失败记录

分析查询最多返回 100 个分组。分析和字段画像分别设置 256 MB、1024 MB 的 DuckDB 管理内存上限，并关闭临时落盘；这不等于整个 Node.js 进程的内存上限。结果行数和字段数在读取及转换结果时校验。

分析查询默认 10 秒超时，字段画像默认 30 秒超时。超时或请求取消时会中断原生查询，待查询结束后再释放连接。自由提问的取消信号也传给 AI 服务商；已发出的模型请求可能产生费用，仍保留保守估算。

两个分析接口均记录成功、空结果和已认证请求的失败，附带登录用户、请求来源、执行阶段和已验证的数据源/指标/计划。无法确认的字段记为空，不伪造默认指标；不保存原始提问、未验证的请求体或上游异常详情。超时返回 504，取消返回 499，空结果或资源限制返回 422。

## 管理 AI

将 `.env.example` 复制为 `.env.local`，生成并保存服务端加密密钥：

```bash
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

把生成值写入 `APP_SETTINGS_KEY`，重启服务后登录“系统管理 → AI 配置”。选择接口协议，填写模型、API 密钥、输入/输出估算单价与调用预算，然后保存。接口地址留空时使用 OpenAI 官方地址；使用其他服务商时填写其 HTTPS API 基础地址（例如以 `/v1` 结尾，不包含 `/chat/completions`）。选择“兼容 Chat Completions”时，服务商需支持标准的 `POST /chat/completions`、返回文本内容和 token 用量。设置保存后立即作用于后续请求，无需再重启。

密钥只在服务端使用 AES-256-GCM 加密保存，页面只返回是否已配置。密钥输入留空会保留已有值。未配置有效 `APP_SETTINGS_KEY` 时，服务端拒绝保存密钥。备份设置时需同时保存该加密密钥，换掉密钥后原设置无法解密。

“测试连接”使用已经保存的配置，实际调用模型并计入用量。没有设置模型价格时不会调用。所有费用均为根据单价计算的估算 USD，以服务商账单为准；网络失败可能仍产生费用，因此会保留保守估算。默认参考单价需由管理员按服务商实际单价核对。Responses 路线使用服务商的结构化输出；兼容 Chat Completions 路线要求模型输出 JSON，并在本地严格校验计划。服务商若使用不同的认证方式、路径或消息格式，需要单独实现适配器。

AI 关闭或未配置时，对比/趋势/关系类推荐问题（固定计划与本地密度图）和手动指标分析仍可正常使用；“各科成绩分布”需要 AI 规划，未配置时会在推荐列表中隐藏。

## 持久化与部署

账号、密码哈希、会话、AI 设置和费用数据保存在 `APP_STATE_DIR`（默认 `records/system`），默认已由 Git 忽略。文件使用原子写入和跨进程锁；服务重启后保留。密码变更或账号停用会立即撤销已有会话。

Docker 使用既有 `records` 数据卷。启动容器后可交互初始化：

```bash
docker compose exec student-analytics node scripts/admin-init.mjs
```

生产环境必须把 `APP_ORIGIN` 配为用户实际访问的 HTTPS 地址，并持久保存 `APP_SETTINGS_KEY`。写接口校验 Origin，登录 Cookie 设置 HttpOnly、SameSite 和生产 Secure；账户与会话不放在浏览器 localStorage。浏览器只可选保存登录账号。

VPS 测试环境已于 2026-10-12 升级到应用登录。确认页面与 API 权限检查正常后，已移除旧网关 HTTP Basic Auth，避免连续出现两套登录。健康检查使用公开 `/api/auth/session` 并验证 `setupRequired=false`；`/api/ai/status` 需要登录，不能作为匿名探针。详见 [部署指南](./deployment.md)。
