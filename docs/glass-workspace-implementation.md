# V4 磨砂玻璃工作台

## 当前背景：烟银玻璃（2026-10-21）

用户在外部参考中选择第 3 组烟银玻璃后，默认背景改为 `smoke`：黑色留白、三层银灰曲面、宽阔摄影棚反射、缓慢曲面变化与少量边缘色散。玻璃边缘和阅读底色同步转为中性银灰，保留既有磨砂压纹与灰绿数据选中态。工作台、登录入口和默认材质预览共用该方向；旧候选保留在早期对比页。

视觉方向参考 Raycast「Glaze 1」，曲面和反射程序为本地实现，无远程壁纸依赖，来源说明见 [第三方声明](third-party-notices.md)。沿用暂停、系统减少动态、减少透明、隐藏/离屏停止和 GPU 不可用降级。类型检查、webpack 生产构建通过；新加载的正式对话页与预览检查 WebGL 错误码 0，深浅主题与暂停交互正常。未调用模型、未部署，未重复运行后端测试；跨浏览器与真机性能仍待验收。

## 实现范围

- 首页进入 AI 对话（账号有权限且无需改密时）；左上角切换 AI 对话和数据浏览，切换整个工作区。
- AI 保留现有账号隔离的历史、统一对话流、结果附件、表格与依据、停止、重试保存、追问和输入草稿。数据展示继续读取真实接口，不使用 V4 预览中的示意结论和数值。
- 数据浏览侧栏进入学习全景、指标分析、数据和报告；右上角进入管理、账号、主题和退出。数据源选择在数据侧栏，AI 模式则在对话标题区；窄屏导航弹层也提供数据源选择。
- 切回数据浏览时返回上次的数据页面；如果正在生成，切换时会向既有停止接口发出请求。数据源、指标等 Workspace 状态及会话、草稿保存在当前页面内，刷新后的会话恢复仍通过现有服务端历史完成。子视图的局部展开与滚动位置不新增持久化契约。
- 首版沿用用户的浅/深主题偏好；深色表现对应 V4 的烟灰玻璃、冷白字和灰绿数据。浅色为相同结构的浅玻璃材质。仅当当前数据集确为 `demo` 时展示“模拟演示数据”。

## 实现取舍

新外观以 `.glass-workspace` 为边界，通过 `app/glass-workspace.css` 与对话 CSS Modules 接入；已有全局样式中的本地修改保留。使用项目既有 React、CSS 和图表能力，不安装玻璃组件库。大面积材质限制为外层玻璃，内容层不重复堆叠模糊；正文与图表不发生光学位移。随后材质增强改用下述本地 WebGL 光学实现。

背景光效是装饰，必须遵循系统减少动态与应用动效偏好。减少透明或不支持背景模糊时使用实色表面。设计参考图不嵌入产品；本轮不复制外部组件源码。既有第三方来源说明继续见 [第三方声明](third-party-notices.md)。

## 材质增强（2026-10-21）

用户反馈首版过于素、玻璃和色散不明显、看不到动态，因此将原来细线式 CSS 背景升级为本仓库 V4 自写程序的生产适配：

- `lib/ui/glass-optics.ts` 两个渲染阶段分别生成流光与玻璃采样；RGB 沿不同方向取样，面板边缘依据圆角矩形距离场折射，高光随光源流动。
- `data-glass-pane` 将真实 DOM 面板几何传给光学程序；历史、主区、结果与输入玻璃分层，切换布局、展开结果、滚动和缩放后重新测量。只有几何变化才读布局；不以 React state 驱动每一帧。
- 显著提高青蓝、紫色、琥珀流光与色散，降低表面实色遮挡；增加厚边、双层深度阴影及彩色抛光轮廓。文字和图表像素不参与折射。
- 顶栏新增流光暂停/播放；应用动效关闭时可直接开启，系统减少动态仍优先；暂停不推进时间，隐藏或离开视口时停止连续绘制。设计上限为 24fps、850,000 个输出像素，不代表已完成实际帧率或设备功耗验收。
- GPU 不可用或丢失上下文时回退 CSS 静态材质；恢复上下文后重新分配资源，减少透明偏好使用实色表面。资源卸载时释放。修正开发模式重复挂载时画布尺寸已匹配但新纹理尚未分配的黑屏问题。
- [无需登录的材质预览](http://127.0.0.1:3000/preview/glass-material) 使用相同组件与材质，仅展示装饰图形，不访问账号、数据集、AI 或业务 API；正式工作台仍需原账号登录。

本轮类型检查、webpack 生产构建、Next 编译/运行错误检查通过；真实浏览器核对 WebGL 错误码 0、浅深主题、真实历史回复与图表展开、数据浏览切换。两次暂停截图哈希相同，运行截图哈希不同，确认时间停止/继续生效。未在本轮重新执行全部后端单元测试；跨浏览器、真机、GPU 故障注入及完整对比度验收仍未覆盖。

## 磨砂压纹增强（2026-10-21）

依据用户补充的磨砂透镜卡片参考图，为卡片增加固定在表面的细密菱形微透镜压纹：7.5 CSS px 节距、光照相关的凹凸高光、局部放大和宽尺度扭折、五点散射柔化。参考图仅用于观察材质，没有嵌入或复制其中图像、文字与图形。

`data-glass-texture`（0–1）独立于磨砂强度；指标卡、概览图表/明细/数据概况、AI 结果卡与输入区使用纹理，外层工作区保留较清透的表面。纹理只处理光学背景，正文与图表几何不扭曲。材质仅在布局变化、滚动或缩放后重新测量；优先采样当前可见面板。静态暂停仍保留磨砂和凹凸层次。

本轮类型检查、生产构建、Next 编译检查通过；真实预览检查浅深主题的材质与文字可读性，WebGL 错误码为 0。新增微透镜与卡片用同一渲染器，不新增依赖。未重跑后端完整测试，跨浏览器和真机性能仍待验收。


## 方案确认后的统一落实（2026-10-21）

用户确认磨砂压纹方向后，将材质统一到正式登录入口、概览指标与图表、AI 附件与输入、指标分析、数据档案、账号、管理总览和成绩导入步骤。普通 `.panel` 自动接入光学背景，显式属性可分别控制磨砂与纹理；密集表格、表单与打印报告保留稳定的阅读底色。登录逻辑、权限、密码规则与后端计算不变。

修复面板入场位移/淡入与背景几何不同步造成的残影：布局变化后最多 1 秒跟踪几何和祖先透明度。暂停流光时仍在这段有界时间内跟随面板，背景时间不推进，结束后停止连续绘制。正常静止布局不逐帧重测。
