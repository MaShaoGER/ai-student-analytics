# 教学成绩导入首期

2026-10-19 开始实施，2026-10-20 完成首期本地验收。目标是把管理员自己的成绩表接入现有授权、聚合统计、AI 问答及报告流程。

## 使用流程

在「系统管理 → 数据集」下载 CSV 模板，或上传已有的 `.xlsx` / UTF-8 CSV。选择工作表和表头所在行，将文件列映射到学生编号、课程、学期、成绩；课程完成状态选填。先运行校验，修正所有阻断错误后再发布。发布时可以创建独立数据集，或为已有成绩数据集发布完整新版本。管理员在账号管理中授予对应数据集后，普通用户才可访问；只读角色仍不能使用 AI 或导出。

发布后在工作台选择新数据源，可使用成绩均分、成绩分布、课程关联与全景、箱线图和学期比较，以及已有的 AI 对话入口。完成状态完整提供时支持课程完成率。未提供学习活动、出勤或作业数据的成绩集不开放相关指标；课程完成率不等于及格率或作业完成率。

## 文件与统计约束

- 首期仅百分制，成绩范围 0–100、最多两位小数。零分有效；空值、缺考和未录入保留为空，不补零。
- 学生编号按文本处理，`001`、`01`、`1` 是三个不同标识。Excel 应将编号保存为文本，避免源文件事先损失精度或前导零。
- 学生编号、课程、学期必填；同一学生—课程—学期必须唯一。补考、重修需要先确定业务口径，首期不自动覆盖或取均值。
- 完成状态只能来自用户明确映射的字段，不能从成绩推算。映射后各行都必须有合法值。
- 首期每文件最多 5 MiB、50,000 条数据行、50 列、10 个工作表；工作表行列及 XLSX 展开体积另有服务端限制。解析错误不静默忽略。
- 不执行工作簿公式，不导入宏，不接受旧版 `.xls`。合并单元格及复杂表头需先整理为一行一条记录的明细表。
- 上传与预览只供管理员检查；AI 接收课程、学期、能力说明和聚合结果，学生明细不会进入模型上下文或统计审计。
- 查询继续执行最少 3 名学生的聚合阈值，学生编号不出现在分析结果中。平均成绩只统计有效成绩对应的样本。

## 存储、发布与版本

上传文件先解析为服务端暂存草稿，草稿由上传管理员持有、有效期一小时，可以主动取消。过期草稿在后续上传时清理，已发布的重试凭据保留24小时；正式成绩版本不会因草稿到期而删除。原始 Excel/CSV 不作为公开文件提供。发布只保存标准化必要字段，未映射列不会进入正式成绩版本。

正式数据和目录在 `APP_STATE_DIR` 下，默认属于私有 `records/system` 运行状态，不能放在 `public` 或提交 Git。部署时必须保留持久卷。成绩版本不可变，目录发布采用已有进程间锁和原子状态写入；更新需要提交看到的 `baseVersion`，版本过期时返回冲突，原版本保持有效。同一草稿和相同发布参数重试返回原结果。

单次 HTTP 分析固定读取同一个版本，即使分析期间管理员发布新版本，也不会将两版数据混用。分析结果、AI 结果引用和导出报告记录所用版本。首期提供版本历史查看；暂不提供逐行追加、合并、历史版本回滚或自动删除正式成绩版本。

备份应同时包含整个 `APP_STATE_DIR` 的目录和版本文件。默认设置下，既有完整 `records` 备份包含这些子目录；备份和恢复仍需停止写入并校验完整性。新增成绩数据的真实部署恢复演练不能用历史演练代替。

## 接口

所有接口均要求管理员身份，不缓存响应；修改接口要求同源，读取和解析有资源上限。

| 方法与路径 | 输入 | 返回 |
| --- | --- | --- |
| `GET /api/admin/imports/template` | 无 | UTF-8 CSV 模板 |
| `POST /api/admin/imports` | 文件原始二进制，`X-File-Name` 为 URL 编码文件名 | `{ draft }`，工作表摘要与到期时间 |
| `POST /api/admin/imports/preview` | `draftId, sheet, headerRow` | `{ selection }`，列、预览、建议映射 |
| `POST /api/admin/imports/validation` | 上述参数加 `mapping` | `{ validation }`，质量汇总、有限错误清单与预览 |
| `POST /api/admin/imports/publications` | 上述参数加 `name`，更新时加 `datasetId, baseVersion` | `{ dataset }`，新目录与版本历史 |
| `DELETE /api/admin/imports` | `{ draftId }` | 取消草稿 |

`sheet` 是从零开始的工作表序号，`headerRow` 是从一开始的表头行号。`mapping` 将标准字段映射到从零开始的原始列序号；必需字段为 `id_student, code_module, code_presentation, score`，`completed` 可省略。发布会重新校验服务端草稿，不信任客户端的校验结果。错误沿用项目 `{ error, code }` 契约。

## 首期边界

不含任意业务表自动建模、AI 自动清洗原始记录、截图识别、教务系统对接、多表关联导入或逐行更新。确定性字段别名匹配不依赖外部模型；AI 辅助映射可在后续接入。真实模型在新导入数据上的效果需要独立验收，模拟模型与本地固定问题成功不能代替该验收。
