2.1

视图切换的入场编排

超出契约

文档契约是 480 / 620 / 760ms、60ms 阶梯；实测当前 27 个元素参与、最晚一段 880ms 延迟 + 620ms 时长，整页要 1.5 秒才安定。切换导航和切模式都会重播，高频操作里这段等待很贵。 提案按频率分级：首屏 760ms、视图切换 420ms、同页模式切换 240ms。

05

其他页面已核实的问题

同类缺陷，逐条读过源码确认

HIGH

图表工坊 / 学科关联：hover 被覆盖成静置色

chart-studio.module.css:58 与 course-relations.module.css:195 都写了 hover 底色 var(--surface-inset)，但同一文件后面的 :global(.glass-workspace) 规则（386 / 324 行）特异性相同且更靠后， 把背景改成 var(--ui-control-bg) —— hover 完全失效。

HIGH

成绩导入 / 系统管理：可点击卡片没有 hover

grade-import.module.css:621 的 .modeOptions label 与 admin-management.module.css:608 的 .checkRow 都是 cursor: pointer 的可点区域，却没有任何 hover 或按压反馈， 只有选中后换一次颜色（且无过渡）。

MED

成绩分布：柱宽变化整条重排，无过渡

score-distribution.tsx:319 把 --bin-count 设为 100 / width，.strip 的 grid-template-columns: repeat(var(--bin-count), …) 直接换列数，没有过渡，切换分组宽度时整条是跳变的。

MED

系统管理：表格行 hover 无过渡，且有一段无效的动效声明

admin-management.module.css:364 行 hover 只换底色、无 transition； 而 1196 行的减少动态效果块里给 .table tbody tr、 .switchButton、.rowActions button 写了 transition: none——这些元素本身从未声明过 transition，属于死代码。

MED

学科全景：两处入场动画漏了减少动态效果

course-panorama.module.css:479 的 .frameGroup / .threshold 入场动画， 没有被同文件 483 行的 reduced-motion 块覆盖（该块只列了 ribbonGroup / ribbon / columnGroup / bar / passFill）。

MED

登录页：入场编排最长约 1.7 秒

motion-auth.css:86-98 的四个信号点延迟到 820 / 960 / 1080 / 1180ms，焦点环再等 1180ms + 560ms 时长 → 约 1740ms； 叠加 login-screen.tsx 里 640ms / 700ms 的延迟段。 登录是高频入口，这段等待偏长。

注：以上均以实际源码行与实测计算样式为依据；未列入的页面没有发现同类问题，不做凑数。

玻璃层级规格

四档配方 · 每个真实控件的具体数值

玻璃不该只有一种配方。我的判断是越靠近数据越克制，越漂浮越厚： 结构层几乎只做色偏和边缘，浮层才允许厚磨砂和深投影， 点阵只留在强调层——一旦进入图表和表格，点阵会干扰读数。 下面这块板子用 CSS 真实渲染了四档的模糊与不透明度（折射和色散在上一节用着色器验证）。

两条硬规则：① 点阵不进数据区；② 不要玻璃叠玻璃——Apple 明确说玻璃无法采样玻璃， 叠层会让模糊成本平方增长且纹理糊成一片。嵌套浮层时用「外层面板转实底」而不是再加一层玻璃。

建议的落地顺序

  1. 第一批（低风险，纯 CSS）：修 3 个 hover 缺陷、补 ::selection、焦点环、历史栏 grid 过渡。改动集中在 glass-workspace.css / glass-controls.css / workbench.css，不动组件逻辑。
  2. 第二批（动效契约）：收紧入场延迟上限与阶梯，按"首屏 / 视图切换 / 同页模式"分三档时长，更新 docs/motion-system.md 契约。
  3. 第三批（图表）：AnalysisChart 开启 universalTransition，保留减少动态效果时的直接切换。
  4. 第四批（细节）：数字变化提示、滚动条配色、玻璃压纹在侧栏选中项上的一致性。
不改：业务逻辑、接口、文案、aria 结构 不新增：依赖 保留：data-motion 开关与系统减少动态效果
