# 学析台 · 工业编辑式界面

2026-10-17，经两轮交互预览后确认并在本地实装。保留当前分支的分析、AI、数据、报告、管理及账号能力；统计内容始终来自项目计算结果。

- 全局圆角令牌 `--corner-radius: 0px`，面板、按钮、切换组、原生下拉浮层、图表柱形/树图和独立报告均为直角。统计圆形与图标形状不属于面板圆角。
- 浅色纸面 `#f0f0e7`、墨色 `#242923`、浅绿 `#c2d3bf`、强调橙 `#f56837`；深色纸面 `#262e29`、正文 `#d5dfce`、浅绿数据区 `#3f5144`。成功、警告、错误继续使用独立语义色。
- 深度只用细线与表面色差；无发光、面板上浮或装饰阴影。边线使用 `--line`，输入使用 `--surface-inset`，浮层使用 `--surface-raised`。
- 橙色标识带桌面 56px、760px 以下 36px；标题区、数据区、图表区与明细共用对齐网格。概览主辅栏约 1.85:1，手机按内容顺序堆叠；只允许表格在自身区域横向滚动。
- Helvetica Neue / Arial + 苹方中文；编号、刻度说明使用 SFMono-Regular / Consolas。4px 间距基准；面板内距 24–28px，手机 16–24px。标题 32–58px、普通正文 13–14px、辅助文字 11–12px；动态数据使用 tabular-nums。
- 顶部导航保留真实按钮，以单条橙色指示线确认当前位置；手机抽屉保留焦点约束、Escape 与焦点恢复。
- 概览指标为真实最高均分、活动总量、最高完成率；首项刻度为 0–100 分，不能把均分或完成率转换成构成占比。复杂图表保留必要多色；选中数据使用橙色，参照用浅绿/同族中性色。
- 主图表为炭黑仪表区，AI 入口使用终端式输入区。几何标记、编号与斜纹只放在导航、分区和关键入口，避免覆盖数据。
- 动效只响应交互：按钮按压 160ms ease-out、导航位移 240ms ease-in-out、图表更新 240ms cubicOut；图表初次显示不做入场计数。沿用 CSS/原有 ECharts，无新增动效依赖。
- 个人设置可关闭交互动效，偏好仅保存在本机；CSS 与 ECharts 共用偏好，同时尊重系统减少动态效果，键盘操作即时响应。
- 报告预览跟随主题，下载与打印保留浅色纸面、直角、真实数据、样本说明和 SQL。
