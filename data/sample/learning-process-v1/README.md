# 学习过程模拟扩展 v1

建立日期：2026-11-03。全部内容虚构，不对应真实学生。使用现有模拟校园数据的 `2025J` 学期：1,200名学生、18门课程、3,600次选课、16周。

原八张 CSV 不变，扩展保存在本子目录。正式 DuckDB 数据目录、账号授权、数据浏览 API 与 AI 工具尚未接入这些新表；目前使用[独立图表样例](../../../docs/design/learning-process-study/index.html)评审数据与视觉方向。

## 文件与关联

| 文件 | 行数 | 粒度与用途 |
| --- | ---: | --- |
| `knowledge_points.csv` | 108 | 每门课程6个知识点，记录顺序、名称与教学周范围 |
| `knowledge_links.csv` | 90 | 明确编排的同课教学顺序；不是统计推断出的相关性 |
| `assessments.csv` | 72 | 每课4次阶段测评，分别安排在第4、8、12、16周 |
| `assessment_items.csv` | 216 | 每课12道评分练习，归属于阶段与知识点；不是带真实题干的完整题库 |
| `learning_resources.csv` | 432 | 知识点的阅读、视频与评分练习资源目录 |
| `stage_scores.csv` | 14,400 | 学生—课程—学期—阶段，含 `observed` 与 `not_observed` |
| `item_attempts.csv` | 50,497 | 练习尝试记录，保留首次与可选再次提交的成绩、时间、时长 |
| `daily_activity.csv` | 434,463 | 日级资源活动桶；部分桶包含多次活动，并非每行都表示一次点击 |
| `visualization-data.json` | 18门课聚合 | 图表数据，不包含学生编号或个人明细 |
| `manifest.json` | — | 固定种子、范围、源文件与输出校验值、生成规则 |

课程事实沿用 `id_student + code_module + code_presentation` 关联；不能只按学生连接，否则会把多门课混在一起。阶段通过 `assessment_id` 关联题目；`item_id` 关联尝试；`knowledge_id` 关联知识点与资源。练习提交在日级活动中通过 `attempt_id` 一对一对应。

`stage_scores.course_completed` 继承原课程完成标记；阶段是否有测评使用 `status` 区分，两者不混用。

## 生成规则

1. **固定种子 `20261103`。** 对每次选课使用独立确定性随机序列，可重新生成相同结果。
2. **成绩锚点来自原总评。** 先合成阶段变化，再用整数百分之一分校准，使有分阶段的均分精确等于原选课成绩。它是由锚点构造的模拟过程，不能作为独立历史证据。
3. **阶段与题目对齐。** 每阶段3道评分练习，最新一次成绩的均分等于阶段成绩；首次和再次尝试分别保留。评分为0–100分的部分得分，不把“达到60分”称为题目完全答对。
4. **缺测与零分分开。** 每阶段标称权重25%；演示总评在有分阶段上重新归一。无足够活动或未到对应阶段时不生成测评，分数为空；180次全程无活动选课的阶段全部未测，保留原源成绩，不为其捏造答卷。共有1,596条未测阶段记录。
5. **日级计数守恒。** 先分配练习提交，再把剩余活动拆到阅读和视频。每个学生—课程—学期—周的 `event_count` 加总，精确等于原 `learning_activity.csv` 的 `activity_count`。
6. **时长单独合成。** `active_minutes` 是模拟观测值，不是真实点击时长推断。测评日期在其阶段内且不晚于截止日，再次提交发生在首次之后。
7. **知识结构明确编排。** 课程知识点和教学顺序是本次的演示课程设计，不声称对应某所学校的正式教学大纲。
8. **预览聚合隐藏小样本。** 非空且少于3名学生的聚合读数、连接隐藏；空活动日为0。知识点读数是最新练习得分的均值，不是经验证的真实能力估计。

阶段曲线每期使用当期有分样本，因此样本量可能变化。不能把后期均分上升直接解读为同一群学生的学习进步；成绩流河保留“未测”通道以帮助理解这种变化。

## 生成与校验

在项目根目录执行：

```sh
python3 scripts/generate-learning-process.py
python3 scripts/validate-learning-process.py
```

生成器默认同步生成单文件 HTML 样例。修改样式请改 `scripts/learning-process-study.template.html`，页面内嵌聚合数据，可以离线打开。

可在独立目录复现，不改工作区产物：

```sh
python3 scripts/generate-learning-process.py --output-dir /tmp/learning-process-check --preview-dir /tmp/learning-process-preview
python3 scripts/validate-learning-process.py --data-dir /tmp/learning-process-check
```

`--term` 可以指定原数据中存在的学期，`--input-dir` 可以指定另一套同结构模拟源，`--seed` 可调整确定性种子。当前已生成并核验的范围是2025J，未声称其它参数组合均已验收。

## 本轮验证

- 独立 CSV 校验通过：目录外键、唯一键、成绩精度、日期、缺测空值、首次与再次尝试顺序。
- 3,420次有测评选课的题目→阶段→源成绩一致；180次无活动选课没有编造阶段成绩。
- 50,497次练习提交均有且仅有一条对应活动；57,600组学生—课程—周计数与原表一致。
- 两次独立生成的8个CSV、聚合JSON与清单共10个文件逐字节相同，原输入校验值未变。
- 本轮没有修改正式数据服务，因此没有运行与本扩展无关的全站构建或完整回归。
